CHAPTER 15 · ข้อมูลและ AI

จัดการตารางข้อมูลด้วย pandas

อ่าน ทำความสะอาด เลือก และสรุปข้อมูลตารางด้วย DataFrame

เมื่อจบบทนี้ นิสิตจะทำได้
  • สร้าง DataFrame กรองแถว จัดการค่าว่าง และ groupby ข้อมูลตามหมวดหมู่ได้
  • DataFrame มีแถวและคอลัมน์
  • เลือกและกรองข้อมูล

แนวคิดและตัวอย่าง

แผนการเรียนบทนี้

การวิเคราะห์ตารางเริ่มจากตรวจข้อมูล ไม่ใช่รีบวาดกราฟ ให้สำรวจจำนวนแถว ชนิดคอลัมน์ และ missing values ก่อนเลือก/กรองข้อมูล จากนั้นค่อยสร้างคอลัมน์และ groupby เพื่อสรุปผล ระวังว่าตัวเลขที่อ่านจาก CSV อาจถูกอ่านเป็นข้อความ

วิธีฝึก: อ่านโจทย์ → ระบุข้อมูลเข้าและผลที่ต้องการ → ทำนาย output → รันและตรวจทีละขั้น → อธิบายด้วยคำของตนเองว่าเหตุใดจึงได้ผลเช่นนั้น

15.1 DataFrame มีแถวและคอลัมน์

สร้างจาก dict ของ list หรืออ่านจาก CSV; ตรวจ `head()`, `shape`, `dtypes` และ `info()` ก่อนวิเคราะห์

ลองคิดเป็นขั้น

ก่อนเขียน ให้แยกข้อมูลที่โจทย์ให้ สิ่งที่ต้องการให้โปรแกรมทำ และผลลัพธ์ที่ควรได้ จากนั้นเลือกแนวคิดนี้มาจัดลำดับวิธีทำ ทดลองรันด้วยค่าตัวอย่าง แล้วตรวจผลทีละบรรทัด ถ้าผลไม่ตรง ให้เทียบค่าตั้งต้นและแต่ละขั้นกับสิ่งที่คาดไว้ก่อนเปลี่ยนโค้ด

15.2 เลือกและกรองข้อมูล

ใช้ `df["column"]` เลือกคอลัมน์ และ boolean condition กรองแถว ควรใช้ `.loc` เมื่อเลือกแถวและคอลัมน์พร้อมกัน

ตัวอย่าง 15.1 · สร้างตารางและกรอง

แนวคิด: สร้าง DataFrame คะแนน แล้วเลือกเฉพาะแถวที่คะแนนถึงเกณฑ์

Python source
import pandas as pd

df = pd.DataFrame({
    "name": ["Mali", "Beam", "Nok"],
    "score": [88, 47, 76],
})
passed = df[df["score"] >= 50]
print(passed[["name", "score"]].to_string(index=False))
Output
name  score
Mali     88
 Nok     76
อธิบายทีละขั้น
  1. dict กำหนดชื่อคอลัมน์และข้อมูลแต่ละคอลัมน์
  2. เงื่อนไขคืน Series ของ True/False
  3. ใช้ mask เลือกแถวผ่านแล้วแสดงเฉพาะคอลัมน์ที่สนใจ

ตัวอย่าง 15.2 · สรุปด้วย groupby

แนวคิด: รวมยอดขายตามหมวดหมู่ด้วยการจัดกลุ่ม

Python source
import pandas as pd

df = pd.DataFrame({
    "category": ["book", "pen", "book", "pen"],
    "sales": [120, 30, 80, 45],
})
summary = df.groupby("category")["sales"].sum()
print(summary.to_string())
Output
category
book    200
pen      75
อธิบายทีละขั้น
  1. groupby แบ่งข้อมูลตาม category
  2. เลือก sales แล้วคำนวณ sum ในแต่ละกลุ่ม
  3. ผลลัพธ์เป็น Series ที่ index เป็นชื่อหมวด

ตัวอย่าง 15.3 · จัดเรียงและเลือกแถว

แนวคิด: เรียงข้อมูลตามคะแนนจากมากไปน้อย แล้วเลือกคอลัมน์ที่จะรายงาน

Python source
import pandas as pd

df = pd.DataFrame({"name": ["Nok", "Mali", "Beam"], "score": [76, 92, 84]})
top = df.sort_values("score", ascending=False).head(2)
print(top.to_string(index=False))
Output
name  score
Mali     92
Beam     84
อธิบายทีละขั้น
  1. sort_values เรียงตามคอลัมน์ score
  2. ascending=False ทำให้ค่าสูงอยู่ก่อน
  3. head(2) เลือกสองแถวแรกหลังเรียง

ข้อ 15.3จัดการค่าว่าง★★ ปานกลาง

สร้างตารางคะแนนมีค่า None หนึ่งแถว แล้วเติมค่าว่างด้วยค่าเฉลี่ยของคอลัมน์

  • ใช้ isna ตรวจค่าว่าง
  • คำนวณ mean
  • fillna ด้วยค่าเฉลี่ยและแสดงผล

1

แนวคำตอบและเหตุผล

การเติมค่าเฉลี่ยเป็นตัวอย่างหนึ่ง ต้องเลือกวิธีตามความหมายของข้อมูลจริง

import pandas as pd
df = pd.DataFrame({"score": [70, None, 90]})
print(df["score"].isna().sum())
df["score"] = df["score"].fillna(df["score"].mean())
print(df["score"].tolist())

  • groupby category
  • aggregate count และ sum
  • แสดง DataFrame สรุป
ตัวอย่างผลลัพธ์

category            
A             2   25

แนวคำตอบและเหตุผล

agg รวมหลายสถิติไว้ในขั้นตอน groupby เดียว

import pandas as pd
df = pd.DataFrame({"category": ["A", "B", "A", "B"], "sales": [10, 20, 15, 5]})
result = df.groupby("category")["sales"].agg(["count", "sum"])
print(result.to_string())

import pandas as pd
df = pd.DataFrame({"name": ["Aom", "Beam", "Nok"], "score": [81, 95, 88]})
top = df.sort_values("score", ascending=False).iloc[0]
print(top["name"], top["score"])

ทำ groupby ก่อนแล้วค่อย sort เพื่อจัดอันดับกลุ่มจากผลรวม ไม่ใช่จากแต่ละแถว

import pandas as pd
df = pd.DataFrame({"category": ["A", "B", "A", "B"], "sales": [12, 30, 25, 15]})
result = df.groupby("category")["sales"].sum().sort_values(ascending=False)
print(result.to_string())
