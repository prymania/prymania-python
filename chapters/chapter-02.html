CHAPTER 02 · พื้นฐาน

ตัวแปร ชนิดข้อมูล และการรับ/แสดงผล

เก็บข้อมูลแต่ละชนิด รับค่าจากผู้ใช้ แปลงชนิดก่อนคำนวณ และสร้าง output ที่อ่านเข้าใจได้

เมื่อจบบทนี้ นิสิตจะทำได้
  • ประกาศและอัปเดตตัวแปร เลือกชนิดข้อมูลให้ตรงงาน รับ input แปลงค่า และจัดรูปแบบ output ได้
  • ตัวแปรคือชื่อที่อ้างถึงข้อมูล
  • ตั้งชื่อให้คนอ่านเข้าใจ

แนวคิดและตัวอย่าง

แผนการเรียนบทนี้

ตัวแปรเป็นจุดที่เก็บข้อมูลเพื่อให้โปรแกรมนำกลับมาใช้ ส่วนชนิดข้อมูลบอกว่าค่านั้นทำอะไรได้บ้าง บทนี้จึงพาเริ่มจากตั้งชื่อและติดตามค่า ต่อด้วยการแยก int, float, str และ bool แล้วจึงรับข้อความจาก input แปลงเป็นชนิดที่คำนวณได้ และจัดรูปแบบคำตอบด้วย f-string

วิธีฝึก: อ่านโจทย์ → ระบุข้อมูลเข้าและผลที่ต้องการ → ทำนาย output → รันและตรวจทีละขั้น → อธิบายด้วยคำของตนเองว่าเหตุใดจึงได้ผลเช่นนั้น

02.1 ตัวแปรคือชื่อที่อ้างถึงข้อมูล

เขียน `credits = 18` แล้ว Python นำชื่อ credits ไปอ้างถึงจำนวนเต็ม 18 เครื่องหมาย = คือการกำหนดค่า ไม่ใช่สมการที่ต้องมีค่าทั้งสองข้างเท่ากัน

ลองคิดเป็นขั้น

ก่อนเขียน ให้แยกข้อมูลที่โจทย์ให้ สิ่งที่ต้องการให้โปรแกรมทำ และผลลัพธ์ที่ควรได้ จากนั้นเลือกแนวคิดนี้มาจัดลำดับวิธีทำ ทดลองรันด้วยค่าตัวอย่าง แล้วตรวจผลทีละบรรทัด ถ้าผลไม่ตรง ให้เทียบค่าตั้งต้นและแต่ละขั้นกับสิ่งที่คาดไว้ก่อนเปลี่ยนโค้ด

02.2 ตั้งชื่อให้คนอ่านเข้าใจ

ใช้ตัวพิมพ์เล็กและขีดล่าง เช่น `course_name` ชื่อแยกตัวพิมพ์เล็กใหญ่ ห้ามขึ้นต้นด้วยตัวเลข และไม่ควรใช้คำสงวนอย่าง `if` หรือ `class`

ตัวอย่าง 02.1 · เก็บข้อมูลนักศึกษา

แนวคิด: กำหนดค่าให้ตัวแปรแล้วส่งไปแสดงผลตามลำดับ

Python source
student_name = "Mali"
credits = 18
is_enrolled = True

print(student_name)
print(credits)
print(is_enrolled)
Output
Mali
18
True
อธิบายทีละขั้น
  1. บรรทัดกำหนดค่าด้านขวาให้ชื่อทางซ้าย
  2. แต่ละ print แสดงค่าปัจจุบันของตัวแปรหนึ่งตัว

ตัวอย่าง 02.2 · อัปเดตแล้วคำนวณค่าใหม่

แนวคิด: ใช้ค่าที่มีอยู่เป็นส่วนหนึ่งของนิพจน์ แล้วบันทึกผลกลับ

Python source
price = 120
quantity = 3
total = price * quantity
total = total - 50

print(f"ยอดสุทธิ {total} บาท")
Output
ยอดสุทธิ 310 บาท
อธิบายทีละขั้น
  1. คูณราคากับจำนวนเพื่อหายอดเริ่มต้น
  2. หักส่วนลดและกำหนดผลใหม่ให้ total
  3. f-string นำค่าปัจจุบันของ total ไปใส่ในข้อความ

ตัวอย่าง 02.3 · ตรวจชนิดที่ได้

แนวคิด: เทียบค่าจำนวนเต็ม ข้อความ และค่าจริง แล้วสังเกตชนิดที่ type รายงาน

Python source
age = 20
name = "Beam"
height = 1.72

print(type(age).__name__)
print(type(name).__name__)
print(type(height).__name__)
Output
int
str
float
อธิบายทีละขั้น
  1. ค่าที่ไม่มีจุดทศนิยมเป็น int
  2. ข้อความอยู่ใน str แม้จะมีตัวเลขปนอยู่

ตัวอย่าง 02.4 · แปลงและจัดรูปแบบ

แนวคิด: จำลองข้อความที่ได้จาก input แล้วแปลงเป็นตัวเลขก่อนคูณ

Python source
price_text = "42.50"
count_text = "4"
total = float(price_text) * int(count_text)

print(f"ยอดรวม {total:.2f} บาท")
Output
ยอดรวม 170.00 บาท
อธิบายทีละขั้น
  1. float แปลงราคาให้คูณทศนิยมได้
  2. int แปลงจำนวนชิ้น
  3. รูปแบบ .2f แสดงทศนิยมสองตำแหน่ง

ตัวอย่าง 02.5 · รับค่าจากผู้ใช้แล้วคำนวณ

แนวคิด: input() คืนข้อความแม้ผู้ใช้พิมพ์ตัวเลข จึงแปลงเป็น int ก่อนนำไปคำนวณ

Python source
name = "Nina"
credits_text = "18"
credits = int(credits_text)
next_year_credits = credits + 6
print(f"{name} will have {next_year_credits} credits")
Output
Nina will have 24 credits
อธิบายทีละขั้น
  1. เก็บข้อมูลที่รับมาในรูปข้อความ
  2. int แปลงข้อความตัวเลขเป็นจำนวนเต็ม
  3. คำนวณค่าถัดไปแล้วใช้ f-string แสดงผล

ตัวอย่าง 02.6 · ปัดเศษและจัดรูปแบบค่า

แนวคิด: ค่าที่คำนวณได้อาจมีทศนิยมยาว ใช้ format specifier กำหนดจำนวนตำแหน่งที่ต้องการแสดง

Python source
price = 89.9
quantity = 3
total = price * quantity
print(f"Unit price: {price:.2f}")
print(f"Total: {total:.2f}")
Output
Unit price: 89.90
Total: 269.70
อธิบายทีละขั้น
  1. price เก็บจำนวนทศนิยม
  2. คูณจำนวนสินค้าเพื่อหายอด
  3. .2f แสดงผลสองตำแหน่งโดยไม่เปลี่ยนชนิดข้อมูลเดิม

แบบฝึกหัดท้ายบท

ทำจากข้อพื้นฐานไปข้อท้าทาย ก่อนเขียนให้จดข้อมูลที่โจทย์ให้ สิ่งที่ต้องหา และลำดับการทำงานสั้น ๆ จากนั้นทำนาย output แล้วรันตรวจ รายการตรวจช่วยไล่เงื่อนไขทีละข้อ หากยังติดให้ย้อนอ่านหัวข้อที่เกี่ยวข้องก่อนเปิดเฉลย ซึ่งมีแนวคิดและ source code ที่รันตรวจแล้ว

  • คำนวณเงินคงเหลือโดยใช้ตัวแปร
  • หารเงินคงเหลือด้วย 3

ข้อ 02.11คำนวณคะแนนเฉลี่ยแบบมีน้ำหนัก★★★ ท้าทาย

  • ตั้งตัวแปรคะแนนและสัดส่วน
  • คูณคะแนนแต่ละส่วนด้วยน้ำหนักก่อนบวก
  • ตรวจว่าน้ำหนักรวมกันเป็น 1.0

แนวคำตอบและเหตุผล

midterm = 78
final = 86
midterm_weight = 0.4
final_weight = 0.6
weighted_score = midterm * midterm_weight + final * final_weight
print(f"Weighted score: {weighted_score:.1f}")
