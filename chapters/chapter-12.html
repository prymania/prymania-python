CHAPTER 12 · ใช้งานจริง

เขียนโปรแกรมเชิงวัตถุด้วย class

รวมสถานะและพฤติกรรมที่สัมพันธ์กันไว้ใน class เพื่อสร้าง object หลายตัว

เมื่อจบบทนี้ นิสิตจะทำได้
  • ประกาศ class, สร้าง instance, กำหนด attribute และเรียก method ได้
  • class เป็นแบบพิมพ์ object เป็นสิ่งที่สร้าง
  • __init__ กำหนดค่าเริ่มต้น

แนวคิดและตัวอย่าง

แผนการเรียนบทนี้

แนวคิด class มีประโยชน์เมื่อข้อมูลกับการกระทำเกี่ยวข้องกันและมีหลาย instance ให้สร้าง บทนี้เริ่มด้วย object ที่เก็บข้อมูลรายวิชา ต่อด้วย method ที่อ่านหรือแก้สถานะ แล้วพิจารณาว่าควรใช้ class เมื่อใดแทนการใช้ dictionary หรือฟังก์ชันธรรมดา

วิธีฝึก: อ่านโจทย์ → ระบุข้อมูลเข้าและผลที่ต้องการ → ทำนาย output → รันและตรวจทีละขั้น → อธิบายด้วยคำของตนเองว่าเหตุใดจึงได้ผลเช่นนั้น

12.1 class เป็นแบบพิมพ์ object เป็นสิ่งที่สร้าง

class อธิบายข้อมูลและพฤติกรรมร่วมกัน ส่วน instance แต่ละตัวเก็บสถานะของตัวเอง

ลองคิดเป็นขั้น

ก่อนเขียน ให้แยกข้อมูลที่โจทย์ให้ สิ่งที่ต้องการให้โปรแกรมทำ และผลลัพธ์ที่ควรได้ จากนั้นเลือกแนวคิดนี้มาจัดลำดับวิธีทำ ทดลองรันด้วยค่าตัวอย่าง แล้วตรวจผลทีละบรรทัด ถ้าผลไม่ตรง ให้เทียบค่าตั้งต้นและแต่ละขั้นกับสิ่งที่คาดไว้ก่อนเปลี่ยนโค้ด

12.2 __init__ กำหนดค่าเริ่มต้น

เมธอด `__init__` รับ self อ้างถึง instance ที่กำลังสร้าง และกำหนด attribute เช่น self.title

ตัวอย่าง 12.1 · สร้าง object รายวิชา

แนวคิด: กำหนดข้อมูลเริ่มต้นใน initializer และใช้ method คืนคำอธิบาย

Python source
class Course:
    def __init__(self, name, credits):
        self.name = name
        self.credits = credits

    def describe(self):
        return f"{self.name} ({self.credits} หน่วยกิต)"

python = Course("Python", 3)
print(python.describe())
Output
Python (3 หน่วยกิต)
อธิบายทีละขั้น
  1. เรียก Course(...) เพื่อสร้าง instance
  2. __init__ บันทึก name และ credits ลงใน object
  3. describe อ่านค่าจาก self แล้วคืนข้อความ

ตัวอย่าง 12.2 · แยกสถานะของแต่ละ object

แนวคิด: สร้างบัญชีสองรายการเพื่อสังเกตว่าแต่ละ instance มี balance คนละค่า

Python source
class Wallet:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance

    def deposit(self, amount):
        self.balance += amount

first = Wallet("Nok", 100)
second = Wallet("Beam")
first.deposit(50)
print(first.balance, second.balance)
Output
150 0
อธิบายทีละขั้น
  1. ค่าเริ่มต้น balance ของ second คือ 0
  2. deposit เปลี่ยนสถานะของ first เท่านั้น
  3. แต่ละ instance มี attribute แยกจากกัน

ตัวอย่าง 12.3 · กำหนดข้อความแสดง object

แนวคิด: เขียน __str__ เพื่อกำหนดรูปแบบที่อ่านง่ายเมื่อใช้ print กับ object

Python source
class Course:
    def __init__(self, code, title):
        self.code = code
        self.title = title

    def __str__(self):
        return f"{self.code}: {self.title}"

print(Course("CS101", "Python"))
Output
CS101: Python
อธิบายทีละขั้น
  1. __init__ จัดเก็บสถานะ
  2. __str__ คืนข้อความแทน object
  3. print เรียก __str__ ให้อัตโนมัติ

แนวคำตอบและเหตุผล

class CartItem:
    def __init__(self, name, price, quantity):
        self.name = name
        self.price = price
        self.quantity = quantity

    def total(self):
        return self.price * self.quantity

items = [CartItem("pen", 12, 3), CartItem("book", 45, 2)]
print(sum(item.total() for item in items))

การตรวจข้อมูลใน method ปกป้อง invariant ของ object

class BankAccount:
    def __init__(self, balance=0):
        self.balance = balance

    def deposit(self, amount):
        if amount <= 0:
            return False
        self.balance += amount
        return True

account = BankAccount(100)
print(account.deposit(50), account.balance)
print(account.deposit(0), account.balance)

แต่ละ instance ควรสร้าง list ของตัวเอง ไม่ใช้ mutable class attribute ร่วมกัน

class Playlist:
    def __init__(self, name):
        self.name = name
        self.songs = []

    def add_song(self, song):
        self.songs.append(song)

    def song_count(self):
        return len(self.songs)

mix = Playlist("Focus")
mix.add_song("Track A")
mix.add_song("Track B")
print(mix.song_count())
