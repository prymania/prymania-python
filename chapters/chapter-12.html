บทที่ 12 · ใช้งานจริง

เขียนโปรแกรมเชิงวัตถุด้วย class

รวมข้อมูลและการทำงานที่เกี่ยวข้องกันไว้ใน class แล้วสร้าง object ได้หลายตัว

เมื่อจบบทนี้ นิสิตจะทำได้

สร้าง class กำหนด attribute ใน __init__ เขียน method สร้าง object หลายตัว และจัดการ list ของ object ได้

12.1 class คือแม่แบบ object คือของจริง

class อธิบายว่าสิ่งหนึ่งมีข้อมูล (attribute) อะไร และทำอะไรได้ (method) ส่วน object คือของจริงที่สร้างจาก class แต่ละตัวมีข้อมูลของตัวเอง

12.2 __init__ และ self

__init__ ทำงานอัตโนมัติตอนสร้าง object ใช้กำหนดค่าเริ่มต้น self คือ object ตัวที่กำลังสร้าง/ใช้งานอยู่ self.name = name จึงหมายถึงเก็บ name ไว้ใน object นี้

topic_12_2.py
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

a = Student("Hobi", 88)
b = Student("SUGA", 72)
print(a.name, a.score)
print(b.name, b.score)
ผลลัพธ์
Hobi 88
SUGA 72
จำง่าย ๆ

ตอนสร้าง Student("Hobi", 88) ไม่ต้องส่ง self Python ใส่ให้เอง

12.3 method: การทำงานของ object

method คือฟังก์ชันใน class รับ self เป็นพารามิเตอร์แรกเสมอ จึงอ่านและแก้ข้อมูลของ object ได้

topic_12_3.py
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def grade(self):
        return "ผ่าน" if self.score >= 50 else "ไม่ผ่าน"

    def add_bonus(self, points):
        self.score += points

s = Student("Jungkook", 45)
print(s.grade())
s.add_bonus(10)
print(s.score, s.grade())
ผลลัพธ์
ไม่ผ่าน
55 ผ่าน

12.4 __str__: กำหนดวิธีแสดงผล

ถ้า print(object) ตรง ๆ จะได้ข้อความอ่านยาก เช่น <__main__.Student object at 0x...> เขียน method __str__ คืนข้อความที่ต้องการแสดงแทน

topic_12_4.py
class Product:
    def __init__(self, name, price):
        self.name = name
        self.price = price

    def __str__(self):
        return f"{self.name} ราคา {self.price:,.2f} บาท"

print(Product("Notebook", 1290))
ผลลัพธ์
Notebook ราคา 1,290.00 บาท

12.5 ทำงานกับ object หลายตัว

เก็บ object ไว้ใน list แล้ววนลูปเรียก method หรืออ่าน attribute ได้เหมือนข้อมูลชนิดอื่น

topic_12_5.py
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

students = [Student("Hobi", 88), Student("SUGA", 72), Student("RM", 95)]
for s in students:
    print(s.name, s.score)
best = max(students, key=lambda s: s.score)
print("สูงสุด:", best.name)
ผลลัพธ์
Hobi 88
SUGA 72
RM 95
สูงสุด: RM
จำง่าย ๆ

key=lambda s: s.score บอก max ให้เทียบด้วยคะแนน

ตัวอย่าง 12.1บัญชีเงินฝาก

object เก็บยอดเงินของตัวเอง และ method ตรวจกติกาก่อนเปลี่ยนยอด

example_12_1.py
class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance

    def deposit(self, amount):
        self.balance += amount

    def withdraw(self, amount):
        if amount > self.balance:
            print(f"{self.owner}: ยอดเงินไม่พอ")
            return
        self.balance -= amount

    def __str__(self):
        return f"{self.owner}: {self.balance:,} บาท"

a = BankAccount("Hobi", 1000)
b = BankAccount("SUGA")
a.deposit(500)
a.withdraw(300)
b.withdraw(100)
print(a)
print(b)
ผลลัพธ์
SUGA: ยอดเงินไม่พอ
Hobi: 1,200 บาท
SUGA: 0 บาท
อธิบาย
  1. balance=0 เป็นค่าเริ่มต้น บัญชีของ SUGA จึงเริ่มที่ 0
  2. withdraw ตรวจยอดก่อนหัก ผู้ใช้ class ไม่ต้องเขียนเงื่อนไขนี้ซ้ำเอง
  3. a และ b เป็นคนละ object ยอดเงินจึงแยกกัน

ตัวอย่าง 12.2ตะกร้าสินค้าแบบ object

class หนึ่งเก็บ object ของอีก class ไว้ใน list

example_12_2.py
class Item:
    def __init__(self, name, price, qty):
        self.name = name
        self.price = price
        self.qty = qty

    def total(self):
        return self.price * self.qty

class Cart:
    def __init__(self):
        self.items = []

    def add(self, item):
        self.items.append(item)

    def total(self):
        return sum(item.total() for item in self.items)

cart = Cart()
cart.add(Item("ปากกา", 12, 3))
cart.add(Item("สมุด", 45, 2))
for item in cart.items:
    print(f"{item.name:<6} {item.total():>5}")
print(f"{'รวม':<6} {cart.total():>5}")
ผลลัพธ์
ปากกา     36
สมุด      90
รวม      126
อธิบาย
  1. Item รู้วิธีคิดราคาของตัวเอง
  2. Cart เก็บ Item หลายตัว และรวมยอดด้วยการเรียก total() ของแต่ละชิ้น
  3. แต่ละ class รับผิดชอบงานของตัวเอง โค้ดจึงแก้ไขง่าย

แนวคำตอบและเหตุผล

method เข้าถึงความกว้างยาวผ่าน self ได้ จึงไม่ต้องส่งค่าเข้าไปซ้ำทุกครั้ง

ex_12_1.py
class Rectangle:
    def __init__(self, width, height):
        self.width = width
        self.height = height

    def area(self):
        return self.width * self.height

    def perimeter(self):
        return 2 * (self.width + self.height)

r = Rectangle(4, 6)
print("พื้นที่", r.area(), "เส้นรอบรูป", r.perimeter())

แนวคำตอบและเหตุผล

object จำสถานะ (value) ไว้ระหว่างการเรียก method แต่ละครั้ง

ex_12_2.py
class Counter:
    def __init__(self):
        self.value = 0

    def increment(self):
        self.value += 1

    def reset(self):
        self.value = 0

c = Counter()
for _ in range(3):
    c.increment()
print(c.value)
c.reset()
print(c.value)

print() เรียก __str__ ให้อัตโนมัติ ใช้ '...' ครอบ f-string เพราะข้างในมี " อยู่แล้ว

ex_12_3.py
class Book:
    def __init__(self, title, author, pages):
        self.title = title
        self.author = author
        self.pages = pages

    def __str__(self):
        return f'"{self.title}" โดย {self.author} ({self.pages} หน้า)'

print(Book("Python 101", "Mark", 320))

โจทย์ให้
เป้าหมาย 2000 บาท ออม 500, 300, 450
ต้องหา
ออมแล้ว 1250 / 2000 บาท (62.5%)
วิธีคิด
  1. เก็บ goal และ saved
  2. progress() คืน saved / goal * 100
ตัวอย่างผลลัพธ์
ออมแล้ว 1250 / 2000 บาท (62.5%)

แนวคำตอบและเหตุผล

ค่าที่คำนวณได้จากข้อมูลอื่น (progress) ทำเป็น method ดีกว่าเก็บเป็น attribute เพราะไม่ต้องคอยอัปเดตตาม

ex_12_4.py
class PiggyBank:
    def __init__(self, goal):
        self.goal = goal
        self.saved = 0

    def save(self, amount):
        self.saved += amount

    def progress(self):
        return self.saved / self.goal * 100

bank = PiggyBank(2000)
for amount in [500, 300, 450]:
    bank.save(amount)
print(f"ออมแล้ว {bank.saved} / {bank.goal} บาท ({bank.progress():.1f}%)")

ข้อ 12.5ห้องเรียนท้าทาย

สร้าง class Student (name, score) และ Classroom ที่มี method add(), average() และ top() คืนนักเรียนคะแนนสูงสุด

เข้าใจโจทย์
โจทย์ให้
Hobi 88, SUGA 72, RM 95
ต้องหา
เฉลี่ย 85.00 และ สูงสุด RM
วิธีคิด
  1. Classroom เก็บ list ของ Student
  2. average() ใช้ sum ของคะแนนทุกคน
  3. top() ใช้ max(..., key=lambda s: s.score)
ตัวอย่างผลลัพธ์
เฉลี่ย 85.00
สูงสุด RM

แนวคำตอบและเหตุผล

Classroom ไม่ต้องรู้รายละเอียดของ Student มากกว่า name และ score การแบ่งหน้าที่แบบนี้ทำให้ขยายโปรแกรมได้ง่าย

ex_12_5.py
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

class Classroom:
    def __init__(self):
        self.students = []

    def add(self, student):
        self.students.append(student)

    def average(self):
        return sum(s.score for s in self.students) / len(self.students)

    def top(self):
        return max(self.students, key=lambda s: s.score)

room = Classroom()
for name, score in [("Hobi", 88), ("SUGA", 72), ("RM", 95)]:
    room.add(Student(name, score))
print(f"เฉลี่ย {room.average():.2f}")
print("สูงสุด", room.top().name)

ข้อ 12.6สินค้าในคลังท้าทาย

สร้าง class Stock มี name และ qty method sell(n) ที่ raise ValueError ถ้าขายเกินจำนวนที่มี แล้วทดสอบขาย 3 และ 10 จากของ 8 ชิ้น

เข้าใจโจทย์
โจทย์ให้
สินค้า 8 ชิ้น ขาย 3 แล้วขาย 10
ต้องหา
ขายครั้งแรกได้ เหลือ 5 ครั้งที่สองแสดงข้อความ error
วิธีคิด
  1. ใน sell ตรวจ n > self.qty แล้ว raise
  2. ผู้เรียกใช้ try/except
  3. ยอดคงเหลือต้องไม่เปลี่ยนเมื่อขายไม่สำเร็จ
ตัวอย่างผลลัพธ์
ขาย 3 ชิ้น เหลือ 5
ผิดพลาด: ปากกา เหลือ 5 ชิ้น ขาย 10 ไม่ได้

แนวคำตอบและเหตุผล

ตรวจก่อนเปลี่ยนค่าทำให้ object อยู่ในสถานะถูกต้องเสมอ ใช้ความรู้ raise จากบทที่ 9 ร่วมกับ class

ex_12_6.py
class Stock:
    def __init__(self, name, qty):
        self.name = name
        self.qty = qty

    def sell(self, n):
        if n > self.qty:
            raise ValueError(f"{self.name} เหลือ {self.qty} ชิ้น ขาย {n} ไม่ได้")
        self.qty -= n

pen = Stock("ปากกา", 8)
for n in [3, 10]:
    try:
        pen.sell(n)
        print(f"ขาย {n} ชิ้น เหลือ {pen.qty}")
    except ValueError as e:
        print("ผิดพลาด:", e)
