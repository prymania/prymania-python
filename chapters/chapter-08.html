ฟังก์ชันและการแบ่งโปรแกรม

รวมคำสั่งที่ทำงานหนึ่งอย่างเป็นฟังก์ชัน เรียกใช้ซ้ำได้ และแบ่งโปรแกรมใหญ่เป็นส่วนเล็ก

เมื่อจบบทนี้ นิสิตจะทำได้

สร้างฟังก์ชันด้วย def ส่งค่าผ่าน parameter รับผลด้วย return และแบ่งโปรแกรมเป็นฟังก์ชันย่อยได้

8.1 def: สร้างฟังก์ชัน

ฟังก์ชันคือชุดคำสั่งที่มีชื่อ สร้างครั้งเดียวด้วย def ชื่อ(): แล้วเรียกใช้กี่ครั้งก็ได้ด้วย ชื่อ() โค้ดในฟังก์ชันจะยังไม่ทำงานจนกว่าจะถูกเรียก

topic_8_1.py
def greet():
    print("สวัสดี")
    print("ยินดีต้อนรับ")

greet()
greet()
ผลลัพธ์
สวัสดี
ยินดีต้อนรับ
สวัสดี
ยินดีต้อนรับ

8.2 parameter: ส่งค่าเข้าฟังก์ชัน

ใส่ชื่อในวงเล็บตอน def (parameter) แล้วส่งค่าจริงตอนเรียก (argument) กำหนดค่าเริ่มต้นได้ เช่น vat=0.07 ถ้าไม่ส่งมาจะใช้ค่านั้น

topic_8_2.py
def greet(name, greeting="สวัสดี"):
    print(f"{greeting} {name}")

greet("Hobi")
greet("SUGA", "หวัดดี")
greet(greeting="Hello", name="RM")
ผลลัพธ์
สวัสดี Hobi
หวัดดี SUGA
Hello RM

8.3 return: ส่งผลกลับ

return ส่งค่ากลับไปให้ผู้เรียกนำไปใช้ต่อ เช่น เก็บในตัวแปรหรือคำนวณต่อ ต่างจาก print ที่แค่แสดงบนจอ

print() ในฟังก์ชันreturn ในฟังก์ชัน
ผลลัพธ์แสดงบนจอส่งค่ากลับให้ผู้เรียก
นำไปคำนวณต่อได้ไหมไม่ได้ (ฟังก์ชันคืน None)ได้
ใช้เมื่องานที่ต้องการแค่แสดงผลฟังก์ชันคำนวณ ตรวจค่า แปลงข้อมูล
topic_8_3.py
def area(width, height):
    return width * height

room = area(4, 5)
total = room + area(2, 3)
print(room, total)

8.4 ตัวแปรในฟังก์ชันเป็นของฟังก์ชัน

ตัวแปรที่สร้างในฟังก์ชัน (local) ใช้ได้เฉพาะในฟังก์ชันนั้น ข้างนอกมองไม่เห็น ให้ส่งค่าเข้าทาง parameter และส่งออกทาง return

topic_8_4.py
def double(n):
    result = n * 2
    return result

answer = double(21)
print(answer)
# print(result)  ← NameError เพราะ result อยู่ในฟังก์ชันเท่านั้น

42

ตัวอย่างโปรแกรม

ตัวอย่าง 8.1แปลงคะแนนเป็นเกรด

แยกกติกาตัดเกรดเป็นฟังก์ชัน แล้วเรียกใช้กับหลายคะแนน

example_8_1.py
def to_grade(score):
    if score >= 80:
        return "A"
    elif score >= 70:
        return "B"
    elif score >= 60:
        return "C"
    elif score >= 50:
        return "D"
    return "F"

for score in [85, 72, 49]:
    print(score, "→", to_grade(score))
ผลลัพธ์
85 → A
72 → B
49 → F
อธิบาย
  1. ฟังก์ชันรับคะแนน 1 ค่า แล้วคืนเกรดเป็นข้อความ
  2. return จบฟังก์ชันทันที จึงไม่ต้องใช้ else ที่บรรทัดสุดท้าย
  3. เขียนกติกาครั้งเดียว ใช้ซ้ำได้ทุกคะแนน

ตัวอย่าง 8.2แบ่งโปรแกรมใบเสร็จเป็นฟังก์ชัน

แต่ละฟังก์ชันทำหน้าที่เดียว: คำนวณ, ใส่ VAT, จัดรูปแบบ

example_8_2.py
def subtotal(price, qty):
    return price * qty

def add_vat(amount, rate=0.07):
    return amount * (1 + rate)

def baht(amount):
    return f"{amount:,.2f} บาท"

price = float(input("ราคา: "))
qty = int(input("จำนวน: "))
before = subtotal(price, qty)
print("ก่อน VAT", baht(before))
print("รวม VAT", baht(add_vat(before)))
ผลลัพธ์ · ตัวที่ขีดเส้นใต้คือค่าที่ผู้ใช้พิมพ์
ราคา: 65.5
จำนวน: 3
ก่อน VAT 196.50 บาท
รวม VAT 210.26 บาท
อธิบาย
  1. แต่ละฟังก์ชันสั้นและทดสอบแยกกันได้
  2. add_vat มีค่าเริ่มต้น rate=0.07 เปลี่ยนได้โดยไม่ต้องแก้ฟังก์ชัน
  3. ส่วนล่างอ่านเหมือนขั้นตอนงาน เพราะรายละเอียดอยู่ในฟังก์ชันแล้ว

แนวคำตอบและเหตุผล

def circle_area(r):
    return 3.14159 * r * r

print(f"{circle_area(5):.2f}")

ผลของ n % 2 == 0 เป็น bool อยู่แล้ว ไม่ต้องเขียน if เพื่อ return True/False

def is_even(n):
    return n % 2 == 0

print(4, is_even(4))
print(7, is_even(7))

ข้อ 8.3แปลงอุณหภูมิทั้งสองทางปานกลาง

เขียน c_to_f(c) และ f_to_c(f) แล้วทดสอบว่า 100°C → °F และแปลงกลับได้ 100 เท่าเดิม

เข้าใจโจทย์
โจทย์ให้
สูตร F = C × 9/5 + 32 และ C = (F − 32) × 5/9
ต้องหา
100 C = 212.0 F และ 212.0 F = 100.0 C
วิธีคิด
  1. เขียนฟังก์ชันละสูตร
  2. นำผลของฟังก์ชันแรกส่งเข้าฟังก์ชันที่สอง
  3. ใส่วงเล็บ (f - 32) ให้ลบก่อนคูณ
ตัวอย่างผลลัพธ์
100 C = 212.0 F
212.0 F = 100.0 C

แนวคำตอบและเหตุผล

เพราะใช้ return จึงส่งผลของฟังก์ชันหนึ่งเข้าอีกฟังก์ชันได้ ถ้าใช้ print แทนจะทำแบบนี้ไม่ได้

ex_8_3.py
def c_to_f(c):
    return c * 9 / 5 + 32

def f_to_c(f):
    return (f - 32) * 5 / 9

f = c_to_f(100)
print(f"100 C = {f} F")
print(f"{f} F = {f_to_c(f)} C")

ข้อ 8.4ส่วนลดแบบมีค่าเริ่มต้นปานกลาง

เขียน discount(price, percent=10) คืนราคาหลังลด แล้วทดสอบโดยไม่ส่ง percent และส่ง percent = 25

วิธีคิด
  1. ใส่ percent=10 ใน def
  2. คำนวณ price * (1 - percent / 100)
  3. เรียกแบบส่งและไม่ส่ง percent

แนวคำตอบและเหตุผล

ค่าเริ่มต้นทำให้กรณีปกติเรียกง่าย แต่ยังปรับได้เมื่อต้องการ

ex_8_4.py
def discount(price, percent=10):
    return price * (1 - percent / 100)

print(discount(800))
print(discount(800, 25))

ข้อ 8.5ฟังก์ชันสรุปคะแนนท้าทาย

เขียน summarize(scores) คืนค่า 3 ค่า (ค่าเฉลี่ย, สูงสุด, ต่ำสุด) แล้วรับผลมาแยกเป็น 3 ตัวแปร

เข้าใจโจทย์
โจทย์ให้
คะแนน [67, 82, 75, 91, 58]
ต้องหา
เฉลี่ย 74.6 สูงสุด 91 ต่ำสุด 58
วิธีคิด
  1. return a, b, c คืนหลายค่าในรูป tuple
  2. รับด้วย avg, high, low = summarize(...)
ตัวอย่างผลลัพธ์
เฉลี่ย 74.6 สูงสุด 91 ต่ำสุด 58

แนวคำตอบและเหตุผล

Python คืนหลายค่าโดยรวมเป็น tuple และแยกออกได้ด้วย unpacking ที่เรียนในบทที่แล้ว

ex_8_5.py
def summarize(scores):
    avg = sum(scores) / len(scores)
    return avg, max(scores), min(scores)

avg, high, low = summarize([67, 82, 75, 91, 58])
print(f"เฉลี่ย {avg:.1f} สูงสุด {high} ต่ำสุด {low}")

ข้อ 8.6เครื่องคิดเงินทอนท้าทาย

เขียนฟังก์ชัน make_change(amount) คืน dict จำนวนเหรียญ/ธนบัตร 100, 20, 10, 5, 1 ที่ใช้ทอนเงินให้ได้จำนวนชิ้นน้อยที่สุด

เข้าใจโจทย์
โจทย์ให้
เงินทอน 287 บาท
ต้องหา
{100: 2, 20: 4, 10: 0, 5: 1, 1: 2}
วิธีคิด
  1. วนผ่าน list ชนิดเงินจากมากไปน้อย
  2. ใช้ // หาจำนวนชิ้น และ % หาเงินที่เหลือ
  3. เก็บผลใน dict แล้ว return
ตัวอย่างผลลัพธ์
{100: 2, 20: 4, 10: 0, 5: 1, 1: 2}

แนวคำตอบและเหตุผล

ฟังก์ชันรวมความรู้หลายบท: ลูป, // กับ %, และ dict ผลลัพธ์อยู่ในรูปข้อมูลจึงนำไปแสดงผลแบบไหนก็ได้

ex_8_6.py
def make_change(amount):
    result = {}
    for coin in [100, 20, 10, 5, 1]:
        result[coin] = amount // coin
        amount %= coin
    return result

print(make_change(287))
