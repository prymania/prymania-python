CHAPTER 08 · พื้นฐาน

ฟังก์ชันและการแบ่งโปรแกรม

ห่อแนวคิดที่ใช้ซ้ำในฟังก์ชัน พร้อมพารามิเตอร์และค่าที่คืนกลับ

เมื่อจบบทนี้ นิสิตจะทำได้
  • ออกแบบฟังก์ชันที่รับข้อมูล ประมวลผล และคืนผลอย่างชัดเจน
  • def ประกาศหน้าที่หนึ่งอย่าง
  • parameter และ argument

แนวคิดและตัวอย่าง

แผนการเรียนบทนี้

ฟังก์ชันช่วยแบ่งโปรแกรมใหญ่ให้เป็นงานย่อยที่อธิบายได้ด้วยประโยคเดียว ในบทนี้ฝึกส่งข้อมูลเข้าทาง parameter คืนผลด้วย return และนำฟังก์ชันเดิมไปใช้หลายครั้ง แยกการคำนวณออกจาก print เพื่อให้ทดสอบและนำผลไปใช้ต่อได้

วิธีฝึก: อ่านโจทย์ → ระบุข้อมูลเข้าและผลที่ต้องการ → ทำนาย output → รันและตรวจทีละขั้น → อธิบายด้วยคำของตนเองว่าเหตุใดจึงได้ผลเช่นนั้น

08.1 def ประกาศหน้าที่หนึ่งอย่าง

บล็อกที่เยื้องใต้ `def` จะทำงานเมื่อเรียกชื่อฟังก์ชัน ไม่ใช่ตอนประกาศ การแบ่งงานช่วยให้ทดสอบและอ่านโปรแกรมได้ง่าย

ลองคิดเป็นขั้น

ก่อนเขียน ให้แยกข้อมูลที่โจทย์ให้ สิ่งที่ต้องการให้โปรแกรมทำ และผลลัพธ์ที่ควรได้ จากนั้นเลือกแนวคิดนี้มาจัดลำดับวิธีทำ ทดลองรันด้วยค่าตัวอย่าง แล้วตรวจผลทีละบรรทัด ถ้าผลไม่ตรง ให้เทียบค่าตั้งต้นและแต่ละขั้นกับสิ่งที่คาดไว้ก่อนเปลี่ยนโค้ด

08.2 parameter และ argument

parameter คือชื่อช่องรับค่าตอนประกาศ ส่วน argument คือค่าที่ส่งตอนเรียก ใช้ชื่อ argument เพื่อให้การเรียกฟังก์ชันอ่านรู้เรื่อง

ลองคิดเป็นขั้น

ก่อนเขียน ให้แยกข้อมูลที่โจทย์ให้ สิ่งที่ต้องการให้โปรแกรมทำ และผลลัพธ์ที่ควรได้ จากนั้นเลือกแนวคิดนี้มาจัดลำดับวิธีทำ ทดลองรันด้วยค่าตัวอย่าง แล้วตรวจผลทีละบรรทัด ถ้าผลไม่ตรง ให้เทียบค่าตั้งต้นและแต่ละขั้นกับสิ่งที่คาดไว้ก่อนเปลี่ยนโค้ด

08.3 return ส่งผลกลับผู้เรียก

ใช้ return เมื่อผู้เรียกต้องนำผลไปคำนวณต่อ หากไม่มี return ฟังก์ชันจะคืน None โดยปริยาย

ตัวอย่าง 08.1 · ฟังก์ชันแปลงหน่วย

แนวคิด: รับค่าตัวเลขและคืนผล ไม่พิมพ์ทับหน้าที่ของผู้เรียก

Python source
def celsius_to_fahrenheit(celsius):
    return celsius * 9 / 5 + 32

morning = celsius_to_fahrenheit(25)
print(f"{morning:.1f} F")
Output
77.0 F
อธิบายทีละขั้น
  1. ประกาศพารามิเตอร์ celsius
  2. return ส่งค่าที่คำนวณแล้วกลับ
  3. ผู้เรียกเลือกจัดรูปแบบการแสดงผลเอง

ตัวอย่าง 08.2 · ค่าเริ่มต้นและ keyword argument

แนวคิด: ตั้งค่าเริ่มต้นให้คำนวณภาษี แต่เปิดให้เปลี่ยนอัตราได้

Python source
def add_tax(price, rate=0.07):
    return price * (1 + rate)

print(add_tax(100))
print(add_tax(100, rate=0.1))
Output
107.0
110.00000000000001
อธิบายทีละขั้น
  1. rate มีค่าเริ่มต้น 0.07
  2. เรียกครั้งแรกใช้ค่าเริ่มต้น
  3. เรียกครั้งที่สองส่งค่าใหม่ด้วยชื่อพารามิเตอร์

ตัวอย่าง 08.3 · แยกตรวจข้อมูลกับคำนวณ

แนวคิด: สร้างฟังก์ชันย่อยที่มีหน้าที่ชัด แล้วให้ฟังก์ชันหลักเรียกใช้

Python source
def is_passing(score):
    return 0 <= score <= 100 and score >= 50

def result_message(score):
    if not 0 <= score <= 100:
        return "invalid score"
    return "pass" if is_passing(score) else "try again"

print(result_message(68))
print(result_message(120))
Output
pass
invalid score
อธิบายทีละขั้น
  1. ฟังก์ชันแรกตอบคำถามเดียวคือผ่านเกณฑ์หรือไม่
  2. ฟังก์ชันที่สองตรวจความถูกต้องก่อน
  3. การแยกงานทำให้ทดสอบแต่ละส่วนและนำกลับมาใช้ได้

ข้อ 08.2คำนวณพื้นที่วงกลม★ ง่าย

สร้างฟังก์ชัน circle_area รับ radius และใช้ค่า pi 3.14159 คำนวณพื้นที่

  • พารามิเตอร์ radius
  • สูตร pi × r ยกกำลังสอง
  • แสดงผลสองตำแหน่ง
ตัวอย่างผลลัพธ์
28.27

แนวคำตอบและเหตุผล

ฟังก์ชันแยกสูตรไว้จุดเดียว ทำให้เปลี่ยนสูตรหรือทดสอบได้ง่าย

def circle_area(radius):
    return 3.14159 * radius ** 2

print(f"{circle_area(3):.2f}")

ข้อ 08.3คืนผลมากกว่าหนึ่งค่า★★ ปานกลาง

เขียนฟังก์ชัน analyze รับ list คะแนนและคืนค่าต่ำสุดกับสูงสุด แล้วทดลองกับ [70, 88, 64]

  • คืน tuple (min, max)
  • รับ list เป็น parameter
  • แกะผลลัพธ์ลงสองตัวแปร
ตัวอย่างผลลัพธ์
64 88

แนวคำตอบและเหตุผล

Python คืนหลายค่าเป็น tuple และสามารถ unpack ได้

def analyze(values):
    return min(values), max(values)

lowest, highest = analyze([70, 88, 64])
print(lowest, highest)

ข้อ 08.4แยกกติกาค่าจัดส่ง★★★ ท้าทาย

เขียนฟังก์ชัน shipping_fee รับยอดซื้อและค่าเริ่มต้น free_limit=500 โดยส่งฟรีเมื่อถึงเกณฑ์ มิฉะนั้นคิด 45 บาท

  • กำหนด default parameter
  • ใช้ if คืนค่า 0 หรือ 45
  • ทดสอบยอดต่ำกว่าและสูงกว่าเกณฑ์
ตัวอย่างผลลัพธ์
45
0

แนวคำตอบและเหตุผล

return ทำให้ทางเลือกแต่ละกรณีส่งค่ากลับได้ทันที

def shipping_fee(total, free_limit=500):
    if total >= free_limit:
        return 0
    return 45

print(shipping_fee(320))
print(shipping_fee(700))

ข้อ 08.5สร้างฟังก์ชันแปลงนาที★ ง่าย

เขียนฟังก์ชัน split_minutes(total) คืนค่าเป็นชั่วโมงและนาทีที่เหลือ ทดลองกับ 135 แล้วแสดงผลเป็น tuple

  • ใช้ // หาชั่วโมง
  • ใช้ % หานาทีที่เหลือ
  • return ค่าทั้งสองกลับเป็น tuple
ตัวอย่างผลลัพธ์
(2, 15)

แนวคำตอบและเหตุผล

ฟังก์ชันที่คืนค่าไม่พิมพ์เองช่วยให้ผู้เรียกเลือกนำผลไปใช้ต่อได้

def split_minutes(total):
    return total // 60, total % 60

print(split_minutes(135))

ข้อ 08.6คำนวณยอดสุทธิด้วยฟังก์ชัน★★ ปานกลาง

สร้างฟังก์ชัน final_price รับราคา จำนวน และ discount_rate ซึ่งมีค่าเริ่มต้น 0.0 คืนยอดหลังหักส่วนลด ทดลองส่วนลด 10%

  • กำหนด default parameter
  • คำนวณยอดก่อนลด
  • คูณส่วนลดแล้วคืนค่าที่เหลือ
ตัวอย่างผลลัพธ์
270.00

แนวคำตอบและเหตุผล

default argument ทำให้เรียกใช้ง่ายในกรณีทั่วไป และส่งค่าใหม่เมื่อมีส่วนลด

def final_price(price, quantity, discount_rate=0.0):
    subtotal = price * quantity
    return subtotal * (1 - discount_rate)

print(f"{final_price(100, 3, 0.1):.2f}")
