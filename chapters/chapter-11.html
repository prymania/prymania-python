CHAPTER 11 · ใช้งานจริง

โมดูล virtual environment และ pip

ใช้ไลบรารีมาตรฐาน ติดตั้งแพ็กเกจแยกสภาพแวดล้อม และจัด dependency ของโปรเจกต์

เมื่อจบบทนี้ นิสิตจะทำได้
  • แยกไฟล์เป็นโมดูล ใช้ venv/pip และบันทึกรายการแพ็กเกจที่ต้องใช้
  • import นำโมดูลมาใช้
  • venv ป้องกัน dependency ชนกัน

แนวคิดและตัวอย่าง

แผนการเรียนบทนี้

เมื่อโปรแกรมแยกหลายไฟล์หรือใช้ไลบรารีเพิ่ม ต้องรู้ว่า Python กำลัง import จากที่ใดและ pip ติดตั้งลง environment ไหน เริ่มจากโมดูลมาตรฐานที่ไม่ต้องติดตั้ง แล้วค่อยสร้าง venv และใช้ python -m pip เพื่อให้ dependency อยู่กับ interpreter ของโปรเจกต์

วิธีฝึก: อ่านโจทย์ → ระบุข้อมูลเข้าและผลที่ต้องการ → ทำนาย output → รันและตรวจทีละขั้น → อธิบายด้วยคำของตนเองว่าเหตุใดจึงได้ผลเช่นนั้น

11.1 import นำโมดูลมาใช้

โมดูลมาตรฐาน เช่น `math`, `statistics` และ `pathlib` ติดมากับ Python ส่วน package ภายนอกต้องติดตั้งใน environment ที่โปรเจกต์ใช้อยู่

ลองคิดเป็นขั้น

ก่อนเขียน ให้แยกข้อมูลที่โจทย์ให้ สิ่งที่ต้องการให้โปรแกรมทำ และผลลัพธ์ที่ควรได้ จากนั้นเลือกแนวคิดนี้มาจัดลำดับวิธีทำ ทดลองรันด้วยค่าตัวอย่าง แล้วตรวจผลทีละบรรทัด ถ้าผลไม่ตรง ให้เทียบค่าตั้งต้นและแต่ละขั้นกับสิ่งที่คาดไว้ก่อนเปลี่ยนโค้ด

11.2 venv ป้องกัน dependency ชนกัน

สร้างด้วย `python -m venv .venv` แล้วติดตั้งแพ็กเกจผ่าน interpreter ของ environment นั้น ทำให้แต่ละวิชาใช้เวอร์ชันคนละชุดได้

ลองคิดเป็นขั้น

ก่อนเขียน ให้แยกข้อมูลที่โจทย์ให้ สิ่งที่ต้องการให้โปรแกรมทำ และผลลัพธ์ที่ควรได้ จากนั้นเลือกแนวคิดนี้มาจัดลำดับวิธีทำ ทดลองรันด้วยค่าตัวอย่าง แล้วตรวจผลทีละบรรทัด ถ้าผลไม่ตรง ให้เทียบค่าตั้งต้นและแต่ละขั้นกับสิ่งที่คาดไว้ก่อนเปลี่ยนโค้ด

11.3 pip และ requirements.txt

ใช้ `python -m pip install -r requirements.txt` ติดตั้ง dependency และบันทึกชื่อแพ็กเกจ/เวอร์ชันที่จำเป็นเพื่อให้คนอื่นสร้าง environment ซ้ำได้

ตัวอย่าง 11.1 · ใช้โมดูลมาตรฐาน

แนวคิด: นำค่า pi จาก math และค่าเฉลี่ยจาก statistics มาใช้แทนการเขียนใหม่

Python source
import math
import statistics

radius = 4
scores = [70, 85, 90]
print(f"พื้นที่วงกลม {math.pi * radius ** 2:.2f}")
print(f"คะแนนเฉลี่ย {statistics.mean(scores):.1f}")
Output
พื้นที่วงกลม 50.27
คะแนนเฉลี่ย 81.7
อธิบายทีละขั้น
  1. import ทำให้เรียกชื่อโมดูลได้
  2. math มีค่าคงที่และฟังก์ชันคณิตศาสตร์
  3. statistics มีฟังก์ชันสรุปข้อมูล

ตัวอย่าง 11.2 · แยกชื่อด้วย alias

แนวคิด: ใช้ alias ตามธรรมเนียมที่พบในงาน data

Python source
import numpy as np
import pandas as pd

scores = np.array([80, 92, 75])
table = pd.DataFrame({"score": scores})
print(table["score"].mean())
Output
82.33333333333333
อธิบายทีละขั้น
  1. np และ pd เป็น alias ที่พบบ่อย
  2. numpy array ใช้คำนวณตัวเลขเป็นชุด
  3. DataFrame จัดข้อมูลเป็นตาราง

ตัวอย่าง 11.3 · ใช้โมดูลมาตรฐานจัดข้อมูล

แนวคิด: เริ่มจาก standard library ก่อนติดตั้ง package เพิ่ม และใช้ Counter เพื่อสรุปความถี่

Python source
from collections import Counter
from statistics import mean

answers = ["A", "B", "A", "C", "A", "B"]
counts = Counter(answers)
print(counts.most_common(1))
print(f"average length={mean([len(x) for x in answers]):.1f}")
Output
[('A', 3)]
average length=1.0
อธิบายทีละขั้น
  1. collections และ statistics มากับ Python ไม่ต้อง pip install
  2. Counter นับความถี่โดยไม่ต้องเขียน dict loop เอง
  3. ติดตั้ง package เพิ่มเฉพาะเมื่อต้องการความสามารถเฉพาะ

แบบฝึกหัดท้ายบท

print(answers["yes"], answers["no"])

ข้อ 11.6อ่าน dependency จาก environment★★ ปานกลาง

ใช้ importlib.metadata ตรวจเวอร์ชันของ pandas และพิมพ์ข้อความบอกว่าคำสั่งติดตั้งควรใช้ `python -m pip` ไม่ใช่ pip เปล่า

  • อ่าน version ของ pandas
  • พิมพ์ชื่อแพ็กเกจกับเวอร์ชัน
  • พิมพ์คำสั่งติดตั้งที่ผูกกับ interpreter
ตัวอย่างผลลัพธ์
pandas 3.0.6
python -m pip install pandas

แนวคำตอบและเหตุผล

python -m pip ช่วยติดตั้ง package ลง environment ของ Python ตัวที่เรียกคำสั่งนี้

from importlib.metadata import version
print(f"pandas {version('pandas')}")
print("python -m pip install pandas")
