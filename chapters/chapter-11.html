โมดูล virtual environment และ pip

นำโมดูลมาตรฐานมาใช้ สร้างโมดูลของตัวเอง และติดตั้งแพ็กเกจเพิ่มด้วย pip ใน virtual environment

จบบทนี้แล้วทำได้

import โมดูลได้หลายรูปแบบ ใช้โมดูลมาตรฐานที่พบบ่อย แยกโค้ดเป็นไฟล์โมดูลเอง และติดตั้งแพ็กเกจด้วย pip/venv

เนื้อหา

11.1 import: นำโมดูลมาใช้

โมดูลคือไฟล์ Python ที่มีฟังก์ชันพร้อมใช้ Python มีโมดูลมาตรฐานมาให้หลายร้อยตัว ไม่ต้องติดตั้งเพิ่ม

รูปแบบเรียกใช้ใช้เมื่อ
import mathmath.sqrt(16)รู้ชัดว่าฟังก์ชันมาจากไหน (แนะนำ)
from math import sqrtsqrt(16)ใช้ไม่กี่ฟังก์ชันบ่อย ๆ
import numpy as npnp.array(...)ชื่อโมดูลยาว ใช้ชื่อย่อตามธรรมเนียม
import math
from statistics import mean

print(math.sqrt(16), math.pi)
print(math.ceil(4.1), math.floor(4.9))
print(mean([70, 85, 90]))

11.3 สร้างโมดูลเอง

ไฟล์ .py ทุกไฟล์เป็นโมดูลได้ เก็บฟังก์ชันที่ใช้บ่อยไว้ในไฟล์หนึ่ง แล้ว import จากอีกไฟล์ที่อยู่ในโฟลเดอร์เดียวกัน

ไฟล์ mytools.py
def vat(amount, rate=0.07):
    return amount * rate

def baht(amount):
    return f"{amount:,.2f} บาท"
import mytools

price = 1500
print(mytools.baht(price))
print("VAT", mytools.baht(mytools.vat(price)))
1,500.00 บาท
VAT 105.00 บาท

จำง่าย ๆ ห้ามตั้งชื่อไฟล์ซ้ำกับโมดูลที่มีอยู่ เช่น random.py เพราะ Python จะ import ไฟล์ของเราแทนของจริง

11.4 pip และ virtual environment

แพ็กเกจที่ไม่ได้มากับ Python (เช่น numpy, pandas) ติดตั้งด้วย pip และควรติดตั้งใน virtual environment (venv) ซึ่งเป็นโฟลเดอร์ Python แยกของแต่ละโปรเจกต์ ทำให้เวอร์ชันแพ็กเกจของแต่ละงานไม่ชนกัน

ทำอะไรคำสั่ง (Windows Terminal ในโฟลเดอร์โปรเจกต์)
สร้าง venvpython -m venv .venv
เปิดใช้งาน.venv\Scripts\activate
ติดตั้งแพ็กเกจpython -m pip install numpy
ดูที่ติดตั้งแล้วpython -m pip list
บันทึกรายการแพ็กเกจpython -m pip freeze > requirements.txt
ติดตั้งตามรายการpython -m pip install -r requirements.txt

จำง่าย ๆ ใน Thonny ใช้เมนู Tools → Manage packages… ค้นชื่อแพ็กเกจแล้วกด Install ได้เลย ไม่ต้องพิมพ์คำสั่ง

11.5 ตรวจว่าติดตั้งแล้วหรือยัง

ถ้า import แล้วเกิด ModuleNotFoundError แปลว่ายังไม่ได้ติดตั้งแพ็กเกจนั้นใน Python ที่กำลังใช้ ใช้ try/except ตรวจและบอกวิธีแก้ได้

try:
    import numpy as np
    print("numpy เวอร์ชัน", np.__version__.split(".")[0] + ".x พร้อมใช้")
except ModuleNotFoundError:
    print("ยังไม่ได้ติดตั้ง: python -m pip install numpy")
numpy เวอร์ชัน 2.x พร้อมใช้

ตัวอย่างโปรแกรม

ตัวอย่าง 11.1 · สุ่มแบ่งกลุ่มงาน

ใช้ random.shuffle สลับรายชื่อ แล้วตัดเป็นกลุ่มละ 2 คน

Python source
import random

random.seed(7)
names = ["Nina", "Beam", "Mali", "Tom", "Ploy", "Arun"]
random.shuffle(names)

for i in range(0, len(names), 2):
    group = names[i:i + 2]
    print(f"กลุ่ม {i // 2 + 1}: {', '.join(group)}")
Output
กลุ่ม 1: Ploy, Nina
กลุ่ม 2: Arun, Tom
กลุ่ม 3: Beam, Mali
อธิบาย
  1. random.seed(7) ทำให้ผลสุ่มเหมือนเดิมทุกครั้ง ลบออกเมื่อใช้จริง
  2. shuffle สลับลำดับใน list เดิม
  3. range(0, len(names), 2) กระโดดทีละ 2 แล้ว slicing [i:i + 2] ตัดกลุ่ม

ตัวอย่าง 11.2 · สถิติคะแนนด้วยโมดูล statistics

ใช้ฟังก์ชันสำเร็จรูปแทนการเขียนสูตรเอง

Python source
import statistics as st

scores = [67, 82, 75, 91, 58, 75, 88]
print("ค่าเฉลี่ย", round(st.mean(scores), 2))
print("มัธยฐาน", st.median(scores))
print("ฐานนิยม", st.mode(scores))
print("ส่วนเบี่ยงเบนมาตรฐาน", round(st.stdev(scores), 2))
Output
ค่าเฉลี่ย 76.57
มัธยฐาน 75
ฐานนิยม 75
ส่วนเบี่ยงเบนมาตรฐาน 11.62
อธิบาย
  1. import statistics as st ตั้งชื่อย่อให้เรียกสั้นลง
  2. median คือค่ากลางเมื่อเรียงแล้ว mode คือค่าที่ซ้ำมากที่สุด
  3. round(x, 2) ปัดทศนิยม 2 ตำแหน่ง

import random

random.seed(3)

แนวคำตอบและเหตุผล

ใช้งานจริงให้เปลี่ยน today เป็น date.today() ตัวอย่างนี้กำหนดวันตายตัวเพื่อให้ตรวจคำตอบได้

from datetime import date

today = date(2026, 11, 1)
exam = date(2026, 12, 15)
days = (exam - today).days
print(f"เหลือ {days} วัน ({days // 7} สัปดาห์ {days % 7} วัน)")

import random

random.seed(10)
for _ in range(3):
    otp = "".join(random.choice("0123456789") for _ in range(6))
    print(otp)

ข้อ 11.5โมดูลแปลงหน่วย★★★ ท้าทาย

มีไฟล์ units.py ที่มีฟังก์ชัน km_to_mile และ kg_to_lb ให้ import มาใช้แปลง 10 km และ 60 kg

ไฟล์ units.py
def km_to_mile(km):
    return km * 0.621371

def kg_to_lb(kg):
    return kg * 2.20462
เข้าใจโจทย์
โจทย์ให้
ไฟล์โมดูล units.py
ต้องหา
10 km = 6.21 mile และ 60 kg = 132.28 lb

วิธีคิด

  1. from units import km_to_mile, kg_to_lb
  2. เรียกฟังก์ชันแล้วจัดรูปทศนิยม 2 ตำแหน่ง
ตัวอย่างผลลัพธ์
10 km = 6.21 mile
60 kg = 132.28 lb

แนวคำตอบและเหตุผล

การแยกฟังก์ชันไว้ในโมดูลทำให้หลายโปรแกรมใช้สูตรเดียวกันได้ แก้ที่ไฟล์เดียวก็มีผลทุกที่

from units import km_to_mile, kg_to_lb

print(f"10 km = {km_to_mile(10):.2f} mile")
print(f"60 kg = {kg_to_lb(60):.2f} lb")

ไฟล์นี้ทำให้คนอื่นติดตั้งแพ็กเกจครบด้วยคำสั่งเดียว python -m pip install -r requirements.txt

packages = {"numpy": "2.2", "pandas": "2.2", "matplotlib": "3.10"}
with open("requirements.txt", "w", encoding="utf-8") as f:
    for name, version in packages.items():
        f.write(f"{name}>={version}\n")

with open("requirements.txt", encoding="utf-8") as f:
    content = f.read()
print(content)
print([line.split(">=")[0] for line in content.split()])
