ไฟล์ ข้อมูล CSV และ JSON

อ่านและเขียนไฟล์ข้อความ CSV และ JSON เพื่อเก็บข้อมูลไว้ใช้ต่อหลังปิดโปรแกรม

เมื่อจบบทนี้ นิสิตจะทำได้

เปิดไฟล์ด้วย with เขียน/อ่านไฟล์ข้อความ อ่านตาราง CSV และบันทึก/โหลดข้อมูลด้วย JSON

10.1 เปิดไฟล์ด้วย with open()

with open(ชื่อไฟล์, โหมด, encoding="utf-8") as f: เปิดไฟล์และปิดให้อัตโนมัติเมื่อจบบล็อก ใส่ encoding="utf-8" เสมอเพื่อให้อ่านภาษาไทยได้

โหมดความหมายถ้ามีไฟล์อยู่แล้ว
"r"อ่าน (ค่าเริ่มต้น)อ่านได้ / ไม่มีไฟล์ → FileNotFoundError
"w"เขียนใหม่ลบเนื้อหาเดิมทิ้ง
"a"เขียนต่อท้ายเพิ่มต่อจากเนื้อหาเดิม
topic_10_1.py
with open("notes.txt", "w", encoding="utf-8") as f:
    f.write("บรรทัดที่ 1\n")
    f.write("บรรทัดที่ 2\n")

with open("notes.txt", encoding="utf-8") as f:
    print(f.read())

บรรทัดที่ 2
จำง่าย ๆ

\n คือขึ้นบรรทัดใหม่ write() ไม่ขึ้นบรรทัดให้เองเหมือน print()

10.4 JSON: บันทึก list/dict ทั้งก้อน

JSON เก็บข้อมูลที่ซ้อนกันได้ เช่น dict ที่มี list อยู่ข้างใน json.dump() บันทึกลงไฟล์ และ json.load() โหลดกลับมาเป็น dict/list เหมือนเดิม

topic_10_4.py
import json

profile = {"name": "Hobi", "skills": ["Python", "SQL"], "year": 2}
with open("profile.json", "w", encoding="utf-8") as f:
    json.dump(profile, f, ensure_ascii=False, indent=2)

with open("profile.json", encoding="utf-8") as f:
    data = json.load(f)
print(data["skills"][0], data["year"])

Python 2

ตัวอย่าง 10.1สรุปคะแนนจากไฟล์ CSV

อ่านไฟล์ คำนวณสถิติ แล้วเขียนรายชื่อคนที่ผ่านลงไฟล์ใหม่

ไฟล์ข้อมูล students.csv (อยู่โฟลเดอร์เดียวกับโปรแกรม)

example_10_1.py
import csv

with open("students.csv", encoding="utf-8") as f:
    rows = list(csv.DictReader(f))

scores = [int(row["score"]) for row in rows]
print(f"{len(rows)} คน เฉลี่ย {sum(scores) / len(scores):.1f}")

with open("passed.txt", "w", encoding="utf-8") as f:
    for row in rows:
        if int(row["score"]) >= 50:
            f.write(row["name"] + "\n")

with open("passed.txt", encoding="utf-8") as f:
    print("ผ่าน:", f.read().split())
ผลลัพธ์
4 คน เฉลี่ย 75.0
ผ่าน: ['Hobi', 'SUGA', 'RM']
อธิบาย
  1. list(csv.DictReader(f)) อ่านทุกแถวเก็บไว้ใช้หลายรอบหลังปิดไฟล์
  2. [int(row["score"]) for row in rows] สร้าง list คะแนนเป็นตัวเลขในบรรทัดเดียว (list comprehension)
  3. เขียนชื่อคนผ่านลงไฟล์ใหม่ทีละบรรทัด แล้วเปิดอ่านกลับเพื่อตรวจ

ตัวอย่าง 10.2รายการสิ่งที่ต้องทำที่จำค่าได้

โหลดรายการจาก JSON (ถ้ามี) เพิ่มงานใหม่ แล้วบันทึกกลับ

example_10_2.py
import json
from pathlib import Path

path = Path("todo.json")
todos = json.loads(path.read_text(encoding="utf-8")) if path.exists() else []
print("ก่อนเพิ่ม:", todos)

todos.append({"task": "อ่านบทที่ 10", "done": False})
todos.append({"task": "ทำแบบฝึกหัด", "done": True})
path.write_text(json.dumps(todos, ensure_ascii=False, indent=2), encoding="utf-8")

for item in json.loads(path.read_text(encoding="utf-8")):
    mark = "✓" if item["done"] else " "
    print(f"[{mark}] {item['task']}")
ผลลัพธ์
ก่อนเพิ่ม: []
[ ] อ่านบทที่ 10
[✓] ทำแบบฝึกหัด
อธิบาย
  1. Path(...).exists() ตรวจว่ามีไฟล์หรือยัง รอบแรกจึงเริ่มจาก list ว่าง
  2. read_text() / write_text() ของ pathlib อ่าน-เขียนทั้งไฟล์ได้ในคำสั่งเดียว
  3. json.dumps() / json.loads() (มี s) แปลงกับข้อความ ส่วน dump() / load() ทำงานกับไฟล์
