CHAPTER 10 · ใช้งานจริง

ไฟล์ ข้อมูล CSV และ JSON

อ่านและเขียนไฟล์ข้อความ CSV และ JSON เพื่อเก็บข้อมูลไว้ใช้ต่อหลังปิดโปรแกรม

จบบทนี้แล้วทำได้

เปิดไฟล์ด้วย with เขียน/อ่านไฟล์ข้อความ อ่านตาราง CSV และบันทึก/โหลดข้อมูลด้วย JSON

เนื้อหา

10.1 เปิดไฟล์ด้วย with open()

with open(ชื่อไฟล์, โหมด, encoding="utf-8") as f: เปิดไฟล์และปิดให้อัตโนมัติเมื่อจบบล็อก ใส่ encoding="utf-8" เสมอเพื่อให้อ่านภาษาไทยได้

โหมดความหมายถ้ามีไฟล์อยู่แล้ว
"r"อ่าน (ค่าเริ่มต้น)อ่านได้ / ไม่มีไฟล์ → FileNotFoundError
"w"เขียนใหม่ลบเนื้อหาเดิมทิ้ง
"a"เขียนต่อท้ายเพิ่มต่อจากเนื้อหาเดิม
with open("notes.txt", "w", encoding="utf-8") as f:
    f.write("บรรทัดที่ 1\n")
    f.write("บรรทัดที่ 2\n")

with open("notes.txt", encoding="utf-8") as f:
    print(f.read())
บรรทัดที่ 1
บรรทัดที่ 2

จำง่าย ๆ \n คือขึ้นบรรทัดใหม่ write() ไม่ขึ้นบรรทัดให้เองเหมือน print()

10.2 อ่านทีละบรรทัด

วน for ผ่านไฟล์ได้ทีละบรรทัด แต่ละบรรทัดมี \n ติดมาด้วย ให้ใช้ strip() ตัดออกก่อนใช้งาน

ไฟล์ todo.txt
ซื้อนม
อ่านบทที่ 10
ส่งการบ้าน
with open("todo.txt", encoding="utf-8") as f:
    for number, line in enumerate(f, start=1):
        print(number, line.strip())
1 ซื้อนม
2 อ่านบทที่ 10
3 ส่งการบ้าน

จำง่าย ๆ enumerate() ให้ทั้งลำดับและค่าในแต่ละรอบ

10.3 CSV: ข้อมูลตาราง

CSV คือไฟล์ตารางที่คั่นคอลัมน์ด้วย , เปิดใน Excel ได้ ใช้โมดูล csv อ่านด้วย DictReader จะได้แต่ละแถวเป็น dict ที่ใช้ชื่อคอลัมน์เป็น key

ไฟล์ students.csv
name,score
Nina,88
Beam,72
Mali,95
Tom,45
import csv

with open("students.csv", encoding="utf-8") as f:
    for row in csv.DictReader(f):
        print(row["name"], int(row["score"]))
Nina 88
Beam 72
Mali 95
Tom 45

จำง่าย ๆ ค่าที่อ่านจาก CSV เป็นข้อความเสมอ ต้องแปลงด้วย int() หรือ float() ก่อนคำนวณ

10.4 JSON: บันทึก list/dict ทั้งก้อน

JSON เก็บข้อมูลที่ซ้อนกันได้ เช่น dict ที่มี list อยู่ข้างใน json.dump() บันทึกลงไฟล์ และ json.load() โหลดกลับมาเป็น dict/list เหมือนเดิม

import json

profile = {"name": "Nina", "skills": ["Python", "SQL"], "year": 2}
with open("profile.json", "w", encoding="utf-8") as f:
    json.dump(profile, f, ensure_ascii=False, indent=2)

with open("profile.json", encoding="utf-8") as f:
    data = json.load(f)
print(data["skills"][0], data["year"])
Python 2

จำง่าย ๆ ensure_ascii=False ให้เก็บภาษาไทยเป็นตัวอักษรที่อ่านออก indent=2 จัดย่อหน้าให้อ่านง่าย

10.5 เลือก CSV หรือ JSON

ทั้งสองแบบเป็นไฟล์ข้อความธรรมดา เลือกตามรูปร่างของข้อมูล

CSVJSON
รูปร่างข้อมูลตาราง แถว × คอลัมน์ซ้อนกันได้ (dict ใน list ใน dict)
เปิดด้วย Excelได้ไม่สะดวก
ชนิดข้อมูลเมื่ออ่านกลับข้อความทั้งหมดตัวเลข/ข้อความ/list ตามเดิม
เหมาะกับข้อมูลรายชื่อ คะแนน ยอดขายการตั้งค่าโปรแกรม ข้อมูลจาก Web API

ตัวอย่าง 10.1 · สรุปคะแนนจากไฟล์ CSV

อ่านไฟล์ คำนวณสถิติ แล้วเขียนรายชื่อคนที่ผ่านลงไฟล์ใหม่

ไฟล์ students.csv
name,score
Nina,88
Beam,72
Mali,95
Tom,45
Python source
import csv

with open("students.csv", encoding="utf-8") as f:
    rows = list(csv.DictReader(f))

scores = [int(row["score"]) for row in rows]
print(f"{len(rows)} คน เฉลี่ย {sum(scores) / len(scores):.1f}")

with open("passed.txt", "w", encoding="utf-8") as f:
    for row in rows:
        if int(row["score"]) >= 50:
            f.write(row["name"] + "\n")

with open("passed.txt", encoding="utf-8") as f:
    print("ผ่าน:", f.read().split())
Output
4 คน เฉลี่ย 75.0
ผ่าน: ['Nina', 'Beam', 'Mali']
อธิบาย
  1. list(csv.DictReader(f)) อ่านทุกแถวเก็บไว้ใช้หลายรอบหลังปิดไฟล์
  2. [int(row["score"]) for row in rows] สร้าง list คะแนนเป็นตัวเลขในบรรทัดเดียว (list comprehension)
  3. เขียนชื่อคนผ่านลงไฟล์ใหม่ทีละบรรทัด แล้วเปิดอ่านกลับเพื่อตรวจ

ตัวอย่าง 10.2 · รายการสิ่งที่ต้องทำที่จำค่าได้

โหลดรายการจาก JSON (ถ้ามี) เพิ่มงานใหม่ แล้วบันทึกกลับ

Python source
import json
from pathlib import Path

path = Path("todo.json")
todos = json.loads(path.read_text(encoding="utf-8")) if path.exists() else []
print("ก่อนเพิ่ม:", todos)

todos.append({"task": "อ่านบทที่ 10", "done": False})
todos.append({"task": "ทำแบบฝึกหัด", "done": True})
path.write_text(json.dumps(todos, ensure_ascii=False, indent=2), encoding="utf-8")

for item in json.loads(path.read_text(encoding="utf-8")):
    mark = "✓" if item["done"] else " "
    print(f"[{mark}] {item['task']}")
Output
ก่อนเพิ่ม: []
[ ] อ่านบทที่ 10
[✓] ทำแบบฝึกหัด
อธิบาย
  1. Path(...).exists() ตรวจว่ามีไฟล์หรือยัง รอบแรกจึงเริ่มจาก list ว่าง
  2. read_text() / write_text() ของ pathlib อ่าน-เขียนทั้งไฟล์ได้ในคำสั่งเดียว
  3. json.dumps() / json.loads() (มี s) แปลงกับข้อความ ส่วน dump() / load() ทำงานกับไฟล์

ข้อ 10.2นับบรรทัดและคำ★ ง่าย

อ่านไฟล์ poem.txt แล้วนับจำนวนบรรทัดและจำนวนคำทั้งหมด

ไฟล์ poem.txt
Python is simple
Python is powerful
learn it step by step today
เข้าใจโจทย์
โจทย์ให้
ไฟล์ poem.txt (3 บรรทัด)
ต้องหา
3 บรรทัด 12 คำ

วิธีคิด

  1. วนอ่านทีละบรรทัด นับบรรทัด
  2. len(line.split()) นับคำในบรรทัด
  3. สะสมทั้งสองค่า
ตัวอย่างผลลัพธ์
3 บรรทัด 12 คำ

แนวคำตอบและเหตุผล

การวนทีละบรรทัดใช้หน่วยความจำน้อย อ่านไฟล์ขนาดใหญ่ได้ และ split() ตัด \n ท้ายบรรทัดให้เอง

lines = 0
words = 0
with open("poem.txt", encoding="utf-8") as f:
    for line in f:
        lines += 1
        words += len(line.split())
print(f"{lines} บรรทัด {words} คำ")

อ่าน students.csv แล้วแสดงชื่อและคะแนนของคนที่ได้คะแนนสูงสุด

ไฟล์ students.csv
name,score

โจทย์ให้

วิธีคิด

  1. ใช้ csv.DictReader
  2. แปลงคะแนนเป็น int ก่อนเปรียบเทียบ
  3. เก็บแถวที่ดีที่สุดระหว่างวน
ตัวอย่างผลลัพธ์
สูงสุด: Mali 95 คะแนน

แนวคำตอบและเหตุผล

ถ้าไม่แปลงเป็น int การเปรียบเทียบข้อความ "95" > "100" จะได้ True เพราะเทียบทีละตัวอักษร

import csv

best = None
with open("students.csv", encoding="utf-8") as f:
    for row in csv.DictReader(f):
        if best is None or int(row["score"]) > int(best["score"]):
            best = row
print(f"สูงสุด: {best['name']} {best['score']} คะแนน")

ข้อ 10.4เขียนไฟล์ CSV★★ ปานกลาง

บันทึกรายการสินค้า 3 ชิ้นลงไฟล์ products.csv ที่มีหัวตาราง name,price แล้วอ่านทั้งไฟล์มาแสดง

เข้าใจโจทย์
โจทย์ให้
สินค้า pen 12, notebook 45, eraser 8
ต้องหา
ไฟล์ CSV 4 บรรทัด (หัวตาราง + 3 แถว)

วิธีคิด

  1. csv.writer(f) แล้ว writerow() หัวตาราง
  2. writerows() เขียนหลายแถวพร้อมกัน
  3. เปิดด้วย newline="" ป้องกันบรรทัดว่างแทรกบน Windows
ตัวอย่างผลลัพธ์
name,price
pen,12
notebook,45
eraser,8

แนวคำตอบและเหตุผล

csv.writer ใส่ , และจัดการข้อความที่มีจุลภาคให้เอง ปลอดภัยกว่าการต่อข้อความด้วยมือ

import csv

products = [["pen", 12], ["notebook", 45], ["eraser", 8]]
with open("products.csv", "w", encoding="utf-8", newline="") as f:
    writer = csv.writer(f)
    writer.writerow(["name", "price"])
    writer.writerows(products)

with open("products.csv", encoding="utf-8") as f:
    print(f.read())

ข้อ 10.5ไฟล์ตั้งค่าโปรแกรม★★★ ท้าทาย

โหลดการตั้งค่าจาก settings.json ถ้าไม่มีไฟล์ให้ใช้ค่าเริ่มต้น {"theme": "light", "font_size": 14} จากนั้นเปลี่ยน theme เป็น dark แล้วบันทึกกลับ

เข้าใจโจทย์
โจทย์ให้
ยังไม่มีไฟล์ settings.json
ต้องหา
แสดงค่าก่อนและหลังเปลี่ยน และไฟล์ถูกสร้างขึ้น

วิธีคิด

  1. ใช้ try/except FileNotFoundError ตอนโหลด
  2. แก้ค่าใน dict
  3. บันทึกด้วย json.dump(..., indent=2)
ตัวอย่างผลลัพธ์
ก่อน: {'theme': 'light', 'font_size': 14}
ในไฟล์: {'theme': 'dark', 'font_size': 14}

แนวคำตอบและเหตุผล

การดัก FileNotFoundError ทำให้โปรแกรมทำงานได้ตั้งแต่ครั้งแรกที่ยังไม่มีไฟล์ ครั้งต่อไปจะโหลดค่าที่บันทึกไว้

import json

try:
    with open("settings.json", encoding="utf-8") as f:
        settings = json.load(f)
except FileNotFoundError:
    settings = {"theme": "light", "font_size": 14}
print("ก่อน:", settings)

settings["theme"] = "dark"
with open("settings.json", "w", encoding="utf-8") as f:
    json.dump(settings, f, indent=2)

with open("settings.json", encoding="utf-8") as f:
    print("ในไฟล์:", json.load(f))

ข้อ 10.6แปลง CSV เป็น JSON★★★ ท้าทาย

อ่าน students.csv แปลงคะแนนเป็นตัวเลข เพิ่มคีย์ passed (คะแนน ≥ 50) แล้วบันทึกเป็น students.json

ไฟล์ students.csv
name,score
Nina,88
Beam,72
Mali,95
Tom,45
เข้าใจโจทย์
โจทย์ให้
ไฟล์ students.csv
ต้องหา
ไฟล์ JSON ที่แต่ละคนมี name, score (ตัวเลข), passed (True/False)

วิธีคิด

  1. อ่านด้วย DictReader
  2. แปลงและเพิ่มคีย์ในแต่ละแถว
  3. json.dump(rows, f, indent=2)
ตัวอย่างผลลัพธ์
[
  {
    "name": "Nina",
    "score": 88,
    "passed": true
  },
  {
    "name": "Beam",
    "score": 72,
    "passed": true
  },
  {
    "name": "Mali",
    "score": 95,
    "passed": true
  },
  {
    "name": "Tom",
    "score": 45,
    "passed": false
  }
]

แนวคำตอบและเหตุผล

JSON เก็บชนิดข้อมูลไว้ได้ ตัวเลขจึงยังเป็นตัวเลขและ True กลายเป็น true ในไฟล์ ซึ่งโหลดกลับเป็น True ได้

import csv
import json

with open("students.csv", encoding="utf-8") as f:
    rows = list(csv.DictReader(f))
for row in rows:
    row["score"] = int(row["score"])
    row["passed"] = row["score"] >= 50

with open("students.json", "w", encoding="utf-8") as f:
    json.dump(rows, f, indent=2)
with open("students.json", encoding="utf-8") as f:
    print(f.read())
