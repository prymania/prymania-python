CHAPTER 07 · พื้นฐาน

โครงสร้างข้อมูล: list, tuple, set และ dict

เก็บข้อมูลหลายค่าในตัวแปรเดียว และเลือกโครงสร้างให้เหมาะกับงาน

จบบทนี้แล้วทำได้

เลือกใช้ list, tuple, set และ dict ให้ตรงงาน เพิ่ม/ลบ/ค้นหาข้อมูล และวนลูปผ่านข้อมูลได้

เนื้อหา

07.1 เลือกใช้แบบไหนดี

ทั้ง 4 แบบเก็บข้อมูลได้หลายค่า แต่มีคุณสมบัติต่างกัน ให้เลือกจากลักษณะงาน

ชนิดเขียนลำดับแก้ไขได้ค่าซ้ำใช้เมื่อ
list[1, 2, 2]มีได้ได้รายการทั่วไป เช่น คะแนนทั้งห้อง
tuple(13.7, 100.5)มีไม่ได้ได้ข้อมูลชุดที่ไม่ควรเปลี่ยน เช่น พิกัด
set{"a", "b"}ไม่มีได้ไม่ได้ตัดค่าซ้ำ / หาค่าร่วม
dict{"Nina": 88}มีได้key ห้ามซ้ำจับคู่ key กับ value เช่น ชื่อ → คะแนน

07.2 list: รายการที่แก้ไขได้

เข้าถึงด้วย index เหมือน string และมี method เพิ่ม/ลบ/เรียงข้อมูล

คำสั่งทำอะไร
items.append(x)เพิ่ม x ท้ายรายการ
items.insert(i, x)แทรก x ที่ตำแหน่ง i
items.remove(x)ลบค่า x ตัวแรกที่เจอ
items.pop()ดึงตัวสุดท้ายออก (คืนค่านั้นมาด้วย)
items.sort()เรียงน้อยไปมาก (reverse=True มากไปน้อย)
len(), sum(), max(), min()นับ / รวม / มากสุด / น้อยสุด
scores = [72, 88, 65]
scores.append(91)
scores.sort()
print(scores)
print(len(scores), sum(scores), max(scores))
print(scores[0], scores[-1])
[65, 72, 88, 91]
4 316 91
65 91

07.3 tuple และ set

tuple เหมือน list แต่แก้ไขไม่ได้ แยกค่าออกเป็นตัวแปรได้ (unpacking) ส่วน set เก็บค่าไม่ซ้ำและหาค่าร่วม/ค่าต่างระหว่างกลุ่มได้

point = (13.75, 100.50)
lat, lon = point
print(lat, lon)

a = {"python", "sql", "excel"}
b = {"python", "java"}
print(a & b)              # มีทั้งสองกลุ่ม
print(sorted(a | b))      # รวมทุกค่า ไม่ซ้ำ
print(sorted(set([3, 1, 3, 2, 1])))
13.75 100.5
{'python'}
['excel', 'java', 'python', 'sql']
[1, 2, 3]

07.4 dict: จับคู่ key กับ value

dict เก็บข้อมูลเป็นคู่ key: value ค้นหาด้วย key แทนตำแหน่ง ใช้ get() เมื่อไม่แน่ใจว่ามี key หรือไม่ และใช้ .items() วนผ่านทุกคู่

scores = {"Nina": 88, "Beam": 72}
scores["Mali"] = 95          # เพิ่ม / แก้ไข
print(scores["Nina"])
print(scores.get("Tom", "ไม่พบ"))
for name, score in scores.items():
    print(name, score)
88
ไม่พบ
Nina 88
Beam 72
Mali 95

จำง่าย ๆ scores["Tom"] ถ้าไม่มี key จะเกิด KeyError ส่วน get() คืนค่าที่กำหนดแทน

ตัวอย่างโปรแกรม

ตัวอย่าง 07.1 · ตะกร้าสินค้า

ใช้ dict เก็บราคาสินค้า และ list เก็บรายการที่ลูกค้าเลือก

Python source
prices = {"pen": 12, "notebook": 45, "eraser": 8}
cart = ["pen", "notebook", "pen", "eraser"]

total = 0
for item in cart:
    total += prices[item]

print("รายการ:", cart)
print("ปากกา", cart.count("pen"), "ด้าม")
print("ยอดรวม", total, "บาท")
Output
รายการ: ['pen', 'notebook', 'pen', 'eraser']
ปากกา 2 ด้าม
ยอดรวม 77 บาท
อธิบาย
  1. prices[item] ค้นราคาจากชื่อสินค้า ไม่ต้องจำตำแหน่ง
  2. list เก็บของซ้ำได้ จึงนับจำนวนด้วย count() ได้
  3. วนลูปสะสมยอดเหมือนบทที่แล้ว แต่ดึงราคาจาก dict

ตัวอย่าง 07.2 · นับความถี่ของคำ

ใช้ dict นับว่าแต่ละคำปรากฏกี่ครั้ง

Python source
words = input("คำ (คั่นด้วยเว้นวรรค): ").split()
counts = {}
for word in words:
    counts[word] = counts.get(word, 0) + 1

for word, n in counts.items():
    print(f"{word}: {n}")
Output · ค่าที่ผู้ใช้พิมพ์แสดงต่อท้ายคำถาม
คำ (คั่นด้วยเว้นวรรค): red blue red green blue red
red: 3
blue: 2
green: 1
อธิบาย
  1. counts.get(word, 0) ได้จำนวนเดิม หรือ 0 ถ้ายังไม่เคยเจอ
  2. บวก 1 แล้วเก็บกลับ เป็นรูปแบบการนับที่ใช้บ่อยมาก
  3. วน .items() เพื่อแสดงทั้ง key และ value

  2. ค่าเฉลี่ย = sum / len

แนวคำตอบและเหตุผล

ฟังก์ชันพื้นฐานเหล่านี้แทนการเขียนลูปเองได้เกือบทั้งหมด

scores = [67, 82, 75, 91, 58]
print("จำนวน", len(scores))
print("รวม", sum(scores))
print(f"เฉลี่ย {sum(scores) / len(scores):.2f}")
print("สูงสุด", max(scores), "ต่ำสุด", min(scores))

แนวคำตอบและเหตุผล

รูปแบบ “list ว่าง + append ในลูป” ใช้สร้างรายการจากข้อมูลที่ผู้ใช้กรอก

items = []
for _ in range(3):
    items.append(input("ของที่จะซื้อ: "))
items.sort()
number = 1
for item in items:
    print(f"{number}. {item}")
    number += 1

โจทย์ให้
list ที่มีชื่อซ้ำ
ต้องหา
3 คน: ['Beam', 'Mali', 'Nok']

วิธีคิด

  1. แปลงเป็น set() เพื่อตัดค่าซ้ำ
  2. sorted() เรียงและคืนเป็น list
  3. len() นับจำนวน
ตัวอย่างผลลัพธ์
3 คน: ['Beam', 'Mali', 'Nok']

แนวคำตอบและเหตุผล

set ไม่เก็บค่าซ้ำ แต่ไม่มีลำดับ จึงใช้ sorted() ให้ผลลัพธ์เรียงแน่นอนทุกครั้ง

names = ["Nok", "Beam", "Nok", "Mali", "Beam"]
unique = sorted(set(names))
print(f"{len(unique)} คน: {unique}")

ข้อ 07.4สมุดโทรศัพท์★★ ปานกลาง

มี dict เบอร์โทร {"Nina": "081-111-2222", "Beam": "089-333-4444"} ให้รับชื่อแล้วแสดงเบอร์ ถ้าไม่มีให้แสดง ไม่พบรายชื่อ

เข้าใจโจทย์
โจทย์ให้
ชื่อที่ผู้ใช้ค้นหา เช่น Tom
ต้องหา
Tom: ไม่พบรายชื่อ

วิธีคิด

  1. ใช้ get(name, "ไม่พบรายชื่อ")
  2. ไม่ต้องใช้ if เพราะ get จัดการกรณีไม่พบให้
ตัวอย่างผลลัพธ์
ค้นหาชื่อ: Tom
Tom: ไม่พบรายชื่อ

แนวคำตอบและเหตุผล

phones[name] จะเกิด KeyError เมื่อไม่มีชื่อ ส่วน get() คืนค่าสำรองแทน โปรแกรมจึงไม่หยุดทำงาน

phones = {"Nina": "081-111-2222", "Beam": "089-333-4444"}
name = input("ค้นหาชื่อ: ")
print(f"{name}: {phones.get(name, 'ไม่พบรายชื่อ')}")

ข้อ 07.5นักเรียนที่ผ่าน★★★ ท้าทาย

จาก dict คะแนน {"Nina": 88, "Beam": 45, "Mali": 72, "Tom": 39} ให้สร้าง list ชื่อคนที่ได้ตั้งแต่ 50 และหาคนที่ได้คะแนนสูงสุด

เข้าใจโจทย์
โจทย์ให้
dict ชื่อ → คะแนน
ต้องหา
ผ่าน: ['Nina', 'Mali'] และ สูงสุด: Nina (88)

วิธีคิด

  1. วน .items() ได้ทั้งชื่อและคะแนน
  2. ถ้า >= 50 ให้ append ชื่อลง list
  3. หาคนสูงสุดด้วยตัวแปร best_name, best_score ระหว่างวน
ตัวอย่างผลลัพธ์
ผ่าน: ['Nina', 'Mali']
สูงสุด: Nina (88)

แนวคำตอบและเหตุผล

ลูปเดียวทำได้สองงาน: คัดกรองคนผ่าน และติดตามค่าสูงสุด best_score เริ่มที่ -1 เพื่อให้คะแนนแรกถูกเก็บแน่นอน

scores = {"Nina": 88, "Beam": 45, "Mali": 72, "Tom": 39}
passed = []
best_name, best_score = "", -1
for name, score in scores.items():
    if score >= 50:
        passed.append(name)
    if score > best_score:
        best_name, best_score = name, score
print("ผ่าน:", passed)
print(f"สูงสุด: {best_name} ({best_score})")

ข้อ 07.6วิชาที่ลงร่วมกัน★★★ ท้าทาย

Nina ลงวิชา Python, Math, English ส่วน Beam ลง Python, Physics, English ให้หาวิชาที่ลงเหมือนกัน วิชาที่ Nina ลงคนเดียว และวิชาทั้งหมด

เข้าใจโจทย์
โจทย์ให้
วิชาของ 2 คน
ต้องหา
วิชาร่วม, วิชาเฉพาะ Nina, วิชาทั้งหมด (เรียงตามตัวอักษร)

วิธีคิด

  1. เก็บเป็น set 2 ชุด
  2. & ค่าร่วม, - ค่าต่าง, | รวมทั้งหมด
  3. ใช้ sorted() ก่อนแสดง
ตัวอย่างผลลัพธ์
ลงร่วมกัน: ['English', 'Python']
Nina คนเดียว: ['Math']
ทั้งหมด: ['English', 'Math', 'Physics', 'Python']

แนวคำตอบและเหตุผล

การดำเนินการ set ตรงกับแผนภาพเวนน์: & ส่วนที่ซ้อนกัน - ส่วนที่มีแต่ฝั่งซ้าย | ทั้งหมด

nina = {"Python", "Math", "English"}
beam = {"Python", "Physics", "English"}
print("ลงร่วมกัน:", sorted(nina & beam))
print("Nina คนเดียว:", sorted(nina - beam))
print("ทั้งหมด:", sorted(nina | beam))
