CHAPTER 18 · ข้อมูลและ AI

แนวคิด Neural Network และการฝึกโมเดล

ต่อยอดแนวคิด ML สู่ neuron, activation, loss และวงจรการเรียนรู้ของ deep learning

เมื่อจบบทนี้ นิสิตจะทำได้
  • อธิบายส่วนประกอบ neural network และจำลอง forward pass ด้วย NumPy ก่อนเลือกใช้ framework
  • Neuron รวม input ด้วยน้ำหนัก
  • Loss วัดความคลาดเคลื่อน

แนวคิดและตัวอย่าง

แผนการเรียนบทนี้

Neural network ไม่ได้เป็นกล่องวิเศษ แต่เป็นการคำนวณซ้ำ ๆ ด้วย weights, bias, activation และ loss เริ่มจากคำนวณ neuron หนึ่งตัวด้วย NumPy เพื่อเห็น forward pass ก่อนพูดถึงการปรับพารามิเตอร์ด้วย gradient และ framework ที่ใช้จริง

วิธีฝึก: อ่านโจทย์ → ระบุข้อมูลเข้าและผลที่ต้องการ → ทำนาย output → รันและตรวจทีละขั้น → อธิบายด้วยคำของตนเองว่าเหตุใดจึงได้ผลเช่นนั้น

18.1 Neuron รวม input ด้วยน้ำหนัก

คำนวณ weighted sum `x @ w + b` แล้วส่งผ่าน activation เช่น ReLU; น้ำหนักและ bias คือค่าที่เรียนรู้จากข้อมูล

ลองคิดเป็นขั้น

ก่อนเขียน ให้แยกข้อมูลที่โจทย์ให้ สิ่งที่ต้องการให้โปรแกรมทำ และผลลัพธ์ที่ควรได้ จากนั้นเลือกแนวคิดนี้มาจัดลำดับวิธีทำ ทดลองรันด้วยค่าตัวอย่าง แล้วตรวจผลทีละบรรทัด ถ้าผลไม่ตรง ให้เทียบค่าตั้งต้นและแต่ละขั้นกับสิ่งที่คาดไว้ก่อนเปลี่ยนโค้ด

18.2 Loss วัดความคลาดเคลื่อน

เปรียบเทียบผลทำนายกับคำตอบจริงด้วย loss function การฝึกพยายามปรับพารามิเตอร์ให้ loss ลดลง โดยใช้ gradient descent หรือ backpropagation

ลองคิดเป็นขั้น

ก่อนเขียน ให้แยกข้อมูลที่โจทย์ให้ สิ่งที่ต้องการให้โปรแกรมทำ และผลลัพธ์ที่ควรได้ จากนั้นเลือกแนวคิดนี้มาจัดลำดับวิธีทำ ทดลองรันด้วยค่าตัวอย่าง แล้วตรวจผลทีละบรรทัด ถ้าผลไม่ตรง ให้เทียบค่าตั้งต้นและแต่ละขั้นกับสิ่งที่คาดไว้ก่อนเปลี่ยนโค้ด

18.3 Framework ช่วยคำนวณ gradient

PyTorch และ TensorFlow จัดการ tensor, automatic differentiation และการฝึกบน hardware; เริ่มจากแนวคิดก่อนติดตั้ง framework ที่เหมาะกับเครื่อง

ตัวอย่าง 18.1 · จำลอง neuron ด้วย NumPy

แนวคิด: คูณ feature ด้วยน้ำหนัก บวก bias และใช้ ReLU

Python source
import numpy as np

features = np.array([2.0, 1.0])
weights = np.array([0.5, -1.0])
bias = 0.25
z = features @ weights + bias
activation = max(0, z)
print(f"z={z:.2f}")
print(f"relu={activation:.2f}")
Output
z=0.25
relu=0.25
อธิบายทีละขั้น
  1. @ คำนวณ dot product ของ feature กับ weight
  2. บวก bias ก่อน activation
  3. ReLU เปลี่ยนค่าติดลบเป็นศูนย์

ตัวอย่าง 18.2 · คำนวณ prediction error

แนวคิด: คำนวณ mean squared error ของผลทำนายกับค่าจริงชุดเล็ก

Python source
import numpy as np

actual = np.array([1.0, 0.0, 1.0])
predicted = np.array([0.8, 0.3, 0.6])
mse = np.mean((actual - predicted) ** 2)
print(f"MSE={mse:.3f}")
Output
MSE=0.097
อธิบายทีละขั้น
  1. หาผลต่างคำตอบจริงกับผลทำนายทีละค่า
  2. ยกกำลังสองทำให้ error ไม่หักล้างกัน
  3. mean สรุปความคลาดเคลื่อนเฉลี่ย

ตัวอย่าง 18.3 · แปลงคะแนนเป็นความน่าจะเป็น

แนวคิด: คำนวณ sigmoid เพื่อบีบค่าจริงใด ๆ ให้อยู่ในช่วง 0 ถึง 1

Python source
import math

def sigmoid(value):
    return 1 / (1 + math.exp(-value))

for logit in (-2, 0, 2):
    print(f"{logit}: {sigmoid(logit):.3f}")
Output
-2: 0.119
0: 0.500
2: 0.881
อธิบายทีละขั้น
  1. logit ต่ำให้ค่าใกล้ 0
  2. ค่า 0 ให้ sigmoid เท่ากับ 0.5
  3. logit สูงให้ค่าใกล้ 1

แบบฝึกหัดท้ายบท

ทำจากข้อพื้นฐานไปข้อท้าทาย ก่อนเขียนให้จดข้อมูลที่โจทย์ให้ สิ่งที่ต้องหา และลำดับการทำงานสั้น ๆ จากนั้นทำนาย output แล้วรันตรวจ รายการตรวจช่วยไล่เงื่อนไขทีละข้อ หากยังติดให้ย้อนอ่านหัวข้อที่เกี่ยวข้องก่อนเปิดเฉลย ซึ่งมีแนวคิดและ source code ที่รันตรวจแล้ว

ข้อ 18.2ใช้ activation★ ง่าย

เขียนฟังก์ชัน ReLU คืน max(0, x) แล้วทดลองกับ -2, 0 และ 3

  • เขียนฟังก์ชันรับค่า
  • คืนค่าที่ไม่ต่ำกว่าศูนย์
  • แสดงผลทั้งสาม
ตัวอย่างผลลัพธ์
[0, 0, 3]

แนวคำตอบและเหตุผล

ReLU ทำให้ค่าติดลบเป็นศูนย์และคงค่าบวกไว้

def relu(value):
    return max(0, value)

print([relu(value) for value in (-2, 0, 3)])

แนวคำตอบและเหตุผล

ข้อ 18.4ทำ forward pass เป็น batch★★★ ท้าทาย

คำนวณ neuron สำหรับสองแถวข้อมูลด้วย matrix multiplication, weight หนึ่งชุดและ bias แล้วใช้ ReLU กับผลทุกแถว

  • สร้าง X รูปร่าง 2x2
  • ใช้ X @ weights + bias
  • ใช้ np.maximum แบบ element-wise
ตัวอย่างผลลัพธ์
[0.2 1.4]

แนวคำตอบและเหตุผล

batch computation คำนวณหลายตัวอย่างพร้อมกันและเป็นแนวคิดเดียวกับ tensor framework

import numpy as np
X = np.array([[1.0, 2.0], [3.0, 1.0]])
weights = np.array([0.5, -0.2])
z = X @ weights + 0.1
print(np.maximum(0, z))

ข้อ 18.5คำนวณ sigmoid★ ง่าย

เขียน sigmoid(value) ด้วย math.exp และแสดงผลสำหรับ -1, 0 และ 1 โดยปัดสามตำแหน่ง

  • import math
  • ใช้สูตร 1/(1+exp(-x))
  • ทดสอบค่าติดลบ ศูนย์ และบวก
ตัวอย่างผลลัพธ์
[0.269, 0.5, 0.731]

แนวคำตอบและเหตุผล

sigmoid เป็น activation ที่เปลี่ยน logit เป็นค่าระหว่าง 0 ถึง 1

import math
def sigmoid(value):
    return 1 / (1 + math.exp(-value))
print([round(sigmoid(x), 3) for x in (-1, 0, 1)])

  • สร้าง array ของ logits และ labels
  • ใช้ argmax เพื่อหา index
  • ใช้ index เดียวกันอ่าน label

แนวคำตอบและเหตุผล

argmax เลือก index ของค่ามากที่สุด ไม่ใช่ค่าความน่าจะเป็นโดยตรง

import numpy as np
logits = np.array([1.2, 0.3, 2.1])
labels = ["cat", "bird", "dog"]
best = int(np.argmax(logits))
print(labels[best], best)
