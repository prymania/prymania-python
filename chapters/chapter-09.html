CHAPTER 09 · ใช้งานจริง

ข้อผิดพลาด การจัดการ exception และ debug

อ่าน error ให้เข้าใจ ดักจับข้อผิดพลาดด้วย try/except และหาสาเหตุเมื่อผลลัพธ์ผิด

จบบทนี้แล้วทำได้

อ่าน traceback หาบรรทัดที่ผิด ใช้ try/except กับ error ที่คาดได้ แจ้ง error เองด้วย raise และไล่หาบั๊กอย่างเป็นขั้นตอน

เนื้อหา

09.1 อ่าน traceback

เมื่อโปรแกรมพัง Python แสดง traceback ให้อ่านจากล่างขึ้นบน: บรรทัดสุดท้ายบอกชนิดและสาเหตุ บรรทัดเหนือขึ้นไปบอกไฟล์และเลขบรรทัดที่เกิดปัญหา

บรรทัดใน tracebackความหมาย
Traceback (most recent call last):เริ่มรายงาน error
File "score.py", line 2, in <module>เกิดที่ไฟล์ score.py บรรทัดที่ 2
score = int(text)โค้ดบรรทัดนั้น
ValueError: invalid literal for int() with base 10: 'abc'ชนิด error: สาเหตุ ← อ่านบรรทัดนี้ก่อน

09.2 error ที่พบบ่อย

error แต่ละชนิดบอกสาเหตุคนละแบบ รู้ชื่อไว้จะเดาที่มาได้เร็ว

Errorเกิดเมื่อตัวอย่าง
ValueErrorค่าชนิดถูกแต่ใช้ไม่ได้int("abc")
TypeErrorใช้ชนิดข้อมูลผิด"5" + 1
ZeroDivisionErrorหารด้วยศูนย์10 / 0
IndexErrorindex เกินขนาด list[1, 2][5]
KeyErrorไม่มี key ใน dict{"a": 1}["b"]
FileNotFoundErrorไม่พบไฟล์open("no.txt")

09.3 try / except: ดักจับ error

ใส่โค้ดที่อาจพังไว้ใน try: ถ้าเกิด error ชนิดที่ระบุ โปรแกรมจะไปทำ except แทนการหยุดทำงาน ระบุชนิด error ให้ชัด อย่าใช้ except: เปล่า ๆ เพราะจะซ่อนบั๊กอื่น

text = input("ตัวเลข: ")
try:
    n = int(text)
    print("สองเท่าคือ", n * 2)
except ValueError:
    print(f"'{text}' ไม่ใช่ตัวเลข")
print("โปรแกรมทำงานต่อได้")
ตัวเลข: abc
'abc' ไม่ใช่ตัวเลข
โปรแกรมทำงานต่อได้

09.4 ดักหลายชนิด และดูข้อความ error

มี except ได้หลายอันสำหรับ error ต่างชนิด และใช้ as e เก็บรายละเอียดของ error ไว้แสดงได้

for a, b in [("10", "2"), ("10", "0"), ("ten", "2")]:
    try:
        print(int(a) / int(b))
    except ZeroDivisionError:
        print("หารด้วยศูนย์ไม่ได้")
    except ValueError as e:
        print("ข้อมูลผิด:", e)
5.0
หารด้วยศูนย์ไม่ได้
ข้อมูลผิด: invalid literal for int() with base 10: 'ten'

09.5 raise: แจ้ง error เอง

เมื่อข้อมูลผิดกติกาของเรา เช่น อายุติดลบ ให้ raise ValueError("ข้อความ") เพื่อหยุดทันทีพร้อมบอกเหตุผล ผู้เรียกจะดักจับด้วย try/except ได้

def set_age(age):
    if age < 0:
        raise ValueError("อายุติดลบไม่ได้")
    return age

try:
    set_age(-5)
except ValueError as e:
    print("ผิดพลาด:", e)
ผิดพลาด: อายุติดลบไม่ได้

09.6 ไล่หาบั๊กเมื่อผลลัพธ์ผิด

บางบั๊กไม่มี error แต่คำตอบผิด (logic error) ให้พิมพ์ค่าระหว่างทางออกมาดู หรือใช้ debugger ของ Thonny เดินโค้ดทีละบรรทัดแล้วดูค่าตัวแปร

ตัวอย่าง 09.1 · ถามจนกว่าจะได้ตัวเลขที่ถูกต้อง

ใช้ while True คู่กับ try/except และ break เมื่อได้ค่าที่ใช้ได้

Python source
while True:
    text = input("อายุ: ")
    try:
        age = int(text)
        if age < 0:
            raise ValueError("อายุติดลบไม่ได้")
        break
    except ValueError as e:
        print("ลองใหม่:", e)

print(f"อายุ {age} ปี")
Output · ค่าที่ผู้ใช้พิมพ์แสดงต่อท้ายคำถาม
อายุ: abc
ลองใหม่: invalid literal for int() with base 10: 'abc'
อายุ: -5
ลองใหม่: อายุติดลบไม่ได้
อายุ: 20
อายุ 20 ปี
อธิบาย
  1. while True วนไม่จบจนกว่าจะเจอ break
  2. abc ทำให้ int() เกิด ValueError ส่วน -5 แปลงได้แต่ผิดกติกา เราจึง raise เอง
  3. ทั้งสองกรณีไปที่ except เดียวกัน เมื่อได้ค่าถูกจึง break ออกจากลูป

ตัวอย่าง 09.2 · ฟังก์ชันหารที่ปลอดภัย

ฟังก์ชันรับผิดชอบจัดการ error เอง แล้วคืนผลที่ผู้เรียกใช้ต่อได้

Python source
def safe_divide(a, b):
    try:
        return a / b
    except ZeroDivisionError:
        return None

for a, b in [(10, 4), (7, 0)]:
    result = safe_divide(a, b)
    if result is None:
        print(f"{a} / {b} = หารไม่ได้")
    else:
        print(f"{a} / {b} = {result}")
Output
10 / 4 = 2.5
7 / 0 = หารไม่ได้
อธิบาย
  1. ถ้าหารได้คืนผลหาร ถ้าหารด้วยศูนย์คืน None (ค่าว่าง)
  2. ผู้เรียกตรวจด้วย is None แล้วเลือกข้อความที่เหมาะ
  3. โปรแกรมไม่หยุดกลางทาง แม้ข้อมูลบางชุดผิด

ข้อ 09.4ตรวจคะแนนด้วย raise★★ ปานกลาง

เข้าใจโจทย์
โจทย์ให้
คะแนน 85, 120, -3
ต้องหา
85 ผ่าน, อีก 2 ค่าแสดงข้อความ error

วิธีคิด

  1. ใช้ if not 0 <= score <= 100: raise ValueError(...)
  2. วนทดสอบทั้ง 3 ค่าใน try/except
ตัวอย่างผลลัพธ์
ใช้ได้: 85
ผิดพลาด: คะแนน 120 อยู่นอกช่วง 0-100
ผิดพลาด: คะแนน -3 อยู่นอกช่วง 0-100

แนวคำตอบและเหตุผล

ฟังก์ชันตรวจกติกาแล้ว raise ส่วนผู้เรียกตัดสินใจเองว่าจะแสดงผลหรือจัดการอย่างไร

def check_score(score):
    if not 0 <= score <= 100:
        raise ValueError(f"คะแนน {score} อยู่นอกช่วง 0-100")
    return score

for s in [85, 120, -3]:
    try:
        print("ใช้ได้:", check_score(s))
    except ValueError as e:
        print("ผิดพลาด:", e)

ข้อ 09.5แก้บั๊กค่าเฉลี่ย★★★ ท้าทาย

โปรแกรมนี้ควรได้ค่าเฉลี่ย 80 แต่ได้ 23.33: total = 0 แล้ว for s in [80, 90, 70]: ข้างในเยื้อง total = s จากนั้นนอกลูป average = total / 3 ให้หาบั๊กด้วยการพิมพ์ค่าระหว่างทางแล้วแก้

เข้าใจโจทย์
โจทย์ให้
โค้ดที่รันได้แต่ผลผิด (logic error)
ต้องหา
เฉลี่ย 80.00

วิธีคิด

  1. พิมพ์ total ทุกรอบ จะเห็นว่าไม่สะสม
  2. total = s ทับค่าเดิม ต้องเป็น total += s
  3. ลบบรรทัด debug ออกเมื่อแก้เสร็จ
ตัวอย่างผลลัพธ์
เฉลี่ย 80.00

แนวคำตอบและเหตุผล

โค้ดเดิม total = s ทับค่าทุกรอบ จึงเหลือแค่ค่าสุดท้าย (70) แล้วหาร 3 ได้ 23.33 การพิมพ์ total ทุกรอบจะเห็นทันทีว่าไม่สะสม และการใช้ len() แทนเลข 3 ป้องกันบั๊กเมื่อจำนวนคะแนนเปลี่ยน

scores = [80, 90, 70]
total = 0
for s in scores:
    total += s
average = total / len(scores)
print(f"เฉลี่ย {average:.2f}")

ข้อ 09.6รวมราคาจากข้อมูลที่ปนข้อผิดพลาด★★★ ท้าทาย

รายการราคาเป็นข้อความ ["120", "abc", "80.5", "", "45"] ให้รวมเฉพาะค่าที่แปลงได้ และนับว่าข้ามไปกี่ค่า

เข้าใจโจทย์
โจทย์ให้
list ราคาที่บางค่าแปลงไม่ได้
ต้องหา
รวม 245.50 บาท (ข้าม 2 ค่า)

วิธีคิด

  1. วนทีละค่า แปลงด้วย float() ใน try
  2. สำเร็จ: บวกเข้า total / ล้มเหลว: เพิ่มตัวนับ skipped
  3. try อยู่ในลูป ค่าที่ผิดจึงไม่หยุดทั้งโปรแกรม
ตัวอย่างผลลัพธ์
รวม 245.50 บาท (ข้าม 2 ค่า)

แนวคำตอบและเหตุผล

ข้อมูลจริงมักมีค่าเสีย การวาง try ไว้ในลูปทำให้จัดการทีละค่า และนับค่าที่ข้ามไว้รายงานได้

prices = ["120", "abc", "80.5", "", "45"]
total = 0
skipped = 0
for text in prices:
    try:
        total += float(text)
    except ValueError:
        skipped += 1
print(f"รวม {total:.2f} บาท (ข้าม {skipped} ค่า)")
