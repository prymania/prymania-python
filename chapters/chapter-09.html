CHAPTER 09 · ใช้งานจริง

ข้อผิดพลาด การจัดการ exception และ debug

อ่าน traceback อย่างมีระบบ ป้องกันข้อผิดพลาดที่คาดหมาย และแก้ที่สาเหตุ

เมื่อจบบทนี้ นิสิตจะทำได้
  • แยก syntax/runtime/logic error ใช้ try-except อย่างเจาะจง และตรวจค่าระหว่างทาง
  • อ่าน traceback จากบรรทัดล่างขึ้นบน
  • try-except ควรจับเฉพาะที่เข้าใจ

แนวคิดและตัวอย่าง

แผนการเรียนบทนี้

การเจอ error เป็นส่วนหนึ่งของการเขียนโปรแกรม เป้าหมายไม่ใช่ซ่อน traceback แต่ใช้มันระบุจุดที่ผิด แล้วตัดสินใจว่าควรแก้สาเหตุหรือจัดการกรณีข้อมูลไม่ถูกต้อง บทนี้แยก syntax, runtime และ logic error พร้อมฝึกจับ exception เฉพาะชนิดที่คาดหมาย

วิธีฝึก: อ่านโจทย์ → ระบุข้อมูลเข้าและผลที่ต้องการ → ทำนาย output → รันและตรวจทีละขั้น → อธิบายด้วยคำของตนเองว่าเหตุใดจึงได้ผลเช่นนั้น

09.1 อ่าน traceback จากบรรทัดล่างขึ้นบน

ชนิด exception และข้อความท้าย traceback มักบอกสาเหตุ เช่น ValueError แปลงข้อความไม่ได้ หรือ ZeroDivisionError หารด้วยศูนย์

ลองคิดเป็นขั้น

ก่อนเขียน ให้แยกข้อมูลที่โจทย์ให้ สิ่งที่ต้องการให้โปรแกรมทำ และผลลัพธ์ที่ควรได้ จากนั้นเลือกแนวคิดนี้มาจัดลำดับวิธีทำ ทดลองรันด้วยค่าตัวอย่าง แล้วตรวจผลทีละบรรทัด ถ้าผลไม่ตรง ให้เทียบค่าตั้งต้นและแต่ละขั้นกับสิ่งที่คาดไว้ก่อนเปลี่ยนโค้ด

09.2 try-except ควรจับเฉพาะที่เข้าใจ

วางคำสั่งเสี่ยงใน try และจับ exception ที่ตั้งใจรับ เช่น ValueError หลีกเลี่ยง except กว้างที่ซ่อนบั๊กอื่น

ลองคิดเป็นขั้น

ก่อนเขียน ให้แยกข้อมูลที่โจทย์ให้ สิ่งที่ต้องการให้โปรแกรมทำ และผลลัพธ์ที่ควรได้ จากนั้นเลือกแนวคิดนี้มาจัดลำดับวิธีทำ ทดลองรันด้วยค่าตัวอย่าง แล้วตรวจผลทีละบรรทัด ถ้าผลไม่ตรง ให้เทียบค่าตั้งต้นและแต่ละขั้นกับสิ่งที่คาดไว้ก่อนเปลี่ยนโค้ด

09.3 แยก logic error ด้วยตัวอย่าง

โปรแกรมอาจทำงานโดยไม่ error แต่สูตรผิด ให้พิมพ์ค่ากลาง ใช้ assert และทดสอบค่าขอบเขต เช่น 0, ค่าติดลบ และค่ามากสุด

ลองคิดเป็นขั้น

ก่อนเขียน ให้แยกข้อมูลที่โจทย์ให้ สิ่งที่ต้องการให้โปรแกรมทำ และผลลัพธ์ที่ควรได้ จากนั้นเลือกแนวคิดนี้มาจัดลำดับวิธีทำ ทดลองรันด้วยค่าตัวอย่าง แล้วตรวจผลทีละบรรทัด ถ้าผลไม่ตรง ให้เทียบค่าตั้งต้นและแต่ละขั้นกับสิ่งที่คาดไว้ก่อนเปลี่ยนโค้ด

ตัวอย่าง 09.1 · แปลงข้อมูลที่อาจไม่ถูกต้อง

แนวคิด: รับข้อความตัวเลขที่ไม่ถูกต้องไว้ใน try แล้วแจ้งข้อผิดพลาดที่เข้าใจได้

Python source
raw = "สิบ"
try:
    quantity = int(raw)
    print(quantity * 2)
except ValueError:
    print("กรุณาป้อนจำนวนเต็ม")
Output
กรุณาป้อนจำนวนเต็ม
อธิบายทีละขั้น
  1. การแปลงเกิด ValueError เมื่อข้อความไม่ใช่จำนวนเต็ม
  2. except จับเฉพาะชนิดที่คาดไว้
  3. โปรแกรมแสดงคำแนะนำแทนการหยุดทันที

ตัวอย่าง 09.2 · ใช้ assert ตรวจสมมติฐาน

แนวคิด: ตรวจช่วงคะแนนก่อนคำนวณเกรด

Python source
score = 85
assert 0 <= score <= 100, "คะแนนต้องอยู่ระหว่าง 0 ถึง 100"
percent = score / 100
print(f"{percent:.0%}")
Output
85%
อธิบายทีละขั้น
  1. assert ยืนยันเงื่อนไขที่โปรแกรมคาดหวัง
  2. ถ้าเงื่อนไขไม่จริงจะได้ AssertionError
  3. เมื่อข้อมูลถูกต้องจึงทำงานต่อ

ตัวอย่าง 09.3 · แปลงข้อมูลหลายรายการอย่างปลอดภัย

แนวคิด: จับ error ต่อหนึ่งรายการเพื่อให้ข้อมูลผิดแถวหนึ่งไม่ทำให้การตรวจรายการอื่นหยุด

Python source
raw_values = ["12", "?", "8"]
numbers = []
for raw in raw_values:
    try:
        numbers.append(int(raw))
    except ValueError:
        print(f"skip invalid value: {raw}")
print(f"valid total: {sum(numbers)}")
Output
skip invalid value: ?
valid total: 20
อธิบายทีละขั้น
  1. แปลงค่าแต่ละรายการแยกกัน
  2. เมื่อเจอ ValueError แจ้งว่าข้ามค่าใด
  3. ข้อมูลที่เหลือยังนำมารวมต่อได้

ข้อ 09.3ตรวจข้อมูลก่อนคำนวณ★★ ปานกลาง

สร้างฟังก์ชัน percentage ที่รับคะแนนและคะแนนเต็ม แล้วปฏิเสธคะแนนเต็มเป็นศูนย์หรือคะแนนติดลบด้วย ValueError

  • ตรวจ max_score ก่อนหาร
  • raise ValueError พร้อมคำอธิบาย
  • แสดงผลกรณีคะแนนเต็ม 80
ตัวอย่างผลลัพธ์
80%

แนวคำตอบและเหตุผล

ตรวจเงื่อนไขที่ต้นฟังก์ชันป้องกันการหารผิดและทำให้สัญญาของฟังก์ชันชัด

def percentage(score, max_score):
    if max_score <= 0:
        raise ValueError("คะแนนเต็มต้องมากกว่าศูนย์")
    return score / max_score * 100

print(f"{percentage(64, 80):.0f}%")

values = [4, 6, 10]
total = 0
for value in values:
    total += value
assert total == 20

แนวคำตอบและเหตุผล

ข้อมูลไม่ถูกต้องควรถูกปฏิเสธอย่างชัดเจนแทนการคืนค่าปลอม

def safe_average(total, count):
    if count <= 0:
        raise ValueError("count must be greater than zero")
    return total / count

for count in (4, 0):
    try:
        print(safe_average(20, count))
    except ValueError as error:
        print(error)

จำกัดขอบเขต try ให้แคบเพื่อไม่กลบข้อผิดพลาดที่ไม่เกี่ยวกับ input

raw_values = ["8", "x", "4"]
numbers = []
for raw in raw_values:
    try:
        numbers.append(int(raw))
    except ValueError:
        print(f"ignored: {raw}")
print(sum(numbers))
