ส่งข้อความถึงอาจารย์

ถามเนื้อหา แจ้งจุดผิด หรือเสนอแนะได้แบบไม่ระบุชื่อ พร้อมคำถามที่พบบ่อยที่อาจารย์ตอบไว้ให้ทุกคน

💬 หน้านี้คืออะไร
  • ช่องส่งข้อความถึงอาจารย์ ไม่ต้องล็อกอิน และไม่ระบุชื่อ
  • ถามเนื้อหาที่ยังไม่เข้าใจ แจ้งจุดผิดในเว็บ หรือบอกว่าอยากให้สอนแบบไหน หรือจะชมก็ได้ ไรเงี้ย 😊 ส่งได้หมดนะ
  • คำถามที่หลายคนน่าจะสงสัย อาจารย์จะตอบไว้ในหัวข้อ คำถามที่พบบ่อย ให้ทุกคนอ่าน

คำถามที่พบบ่อย

คำถามจากเพื่อน ๆ ที่อาจารย์เลือกมาตอบให้ทุกคนอ่าน ใหม่สุดอยู่บน · กดที่คำถามเพื่อดูคำตอบ

ไม่ระบุชื่อจริงไหม

อาจารย์เห็นเวลาที่ส่ง · ประเภท · บท · ข้อความระบบไม่เก็บชื่อ · อีเมล · รหัสนิสิต · IP · คุกกี้เพื่อนเห็นเฉพาะคำถามที่อาจารย์เลือกขึ้นคำถามที่พบบ่อย และอาจารย์อาจเกลาคำถามใหม่ก่อนระวังเองถ้าเขียนสิ่งที่บอกตัวตน เช่น ชื่อเล่น หรือ "ผมที่นั่งหน้าสุด" ระบบก็ช่วยปิดให้ไม่ได้

ส่งแล้วแก้หรือลบเองไม่ได้ ถ้าส่งผิด ส่งข้อความใหม่บอกอาจารย์ได้เลย

💻 ในโลกคอมพิวเตอร์: กด "ส่ง" แล้วข้อความไปไหน
  • เบราว์เซอร์แพ็กข้อความเป็นคำขอแบบ HTTP POST ส่งไปที่ Google Apps Script ซึ่งทำหน้าที่เป็นเซิร์ฟเวอร์เล็ก ๆ แล้วเขียนลงแถวใหม่ใน Google Sheet
  • คำถามที่พบบ่อยใช้ทางกลับกัน คือ HTTP GET ขอรายการมาเป็น JSON แล้ว JavaScript ในหน้าเว็บสร้างเป็นรายการให้อ่าน — หลักเดียวกับบท Web API ที่เราใช้ requests.get() กับ .json()
  • กันบอตสแปมด้วยช่องดัก (honeypot) ที่คนมองไม่เห็นแต่บอตชอบกรอก และจำกัดอัตรา (rate limit) ว่ารับได้กี่ข้อความต่อ 10 นาที
  • เว็บใหญ่ ๆ ใช้หลักเดียวกัน แค่เปลี่ยน Google Sheet เป็นฐานข้อมูล และเปลี่ยนช่องดักเป็น CAPTCHA
