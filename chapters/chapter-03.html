ตัวอย่าง 3.1แปลงนาทีเป็นชั่วโมงและนาที

ใช้ // หาชั่วโมงเต็ม และ % หานาทีที่เหลือ

example_3_1.py
total = int(input("จำนวนนาที: "))
hours = total // 60
minutes = total % 60
print(f"{total} นาที = {hours} ชั่วโมง {minutes} นาที")
ผลลัพธ์ · ตัวที่ขีดเส้นใต้คือค่าที่ผู้ใช้พิมพ์
จำนวนนาที: 157
157 นาที = 2 ชั่วโมง 37 นาที
อธิบาย
  1. 157 // 60 = 2 คือ 2 ชั่วโมงเต็ม
  2. 157 % 60 = 37 คือเศษที่เหลือ 37 นาที
  3. รูปแบบ // คู่กับ % ใช้ได้กับโจทย์แบ่งของเป็นชุดทุกแบบ

ตัวอย่าง 3.2ตรวจปีอธิกสุรทิน

ปีอธิกสุรทินคือปีที่หาร 4 ลงตัวแต่หาร 100 ไม่ลงตัว หรือปีที่หาร 400 ลงตัว

example_3_2.py
year = int(input("ปี ค.ศ.: "))
is_leap = (year % 4 == 0 and year % 100 != 0) or year % 400 == 0
print(f"{year} เป็นปีอธิกสุรทิน: {is_leap}")
ผลลัพธ์ · ตัวที่ขีดเส้นใต้คือค่าที่ผู้ใช้พิมพ์
ปี ค.ศ.: 2024
2024 เป็นปีอธิกสุรทิน: True
อธิบาย
  1. year % 4 == 0 แปลว่าหาร 4 ลงตัว (เศษเป็น 0)
  2. วงเล็บจับกลุ่ม “หาร 4 ลงตัว และหาร 100 ไม่ลงตัว” ไว้ด้วยกัน
  3. or ทำให้ปีที่หาร 400 ลงตัวผ่านด้วย

แนวคำตอบและเหตุผล

แบ่งของที่เป็นชิ้นเต็มต้องใช้ // ถ้าใช้ / จะได้ 5.75 ชิ้น ซึ่งแบ่งจริงไม่ได้

ex_3_1.py
snacks = int(input("จำนวนขนม: "))
friends = int(input("จำนวนเพื่อน: "))
print(f"คนละ {snacks // friends} ชิ้น")
print(f"เหลือ {snacks % friends} ชิ้น")

  2. เส้นรอบรูปต้องใส่วงเล็บให้บวกก่อนคูณ
  3. แสดงผลพร้อมหน่วย

กว้าง: 7.5
ยาว: 12
พื้นที่ 90.0 ตร.ซม.
เส้นรอบรูป 39.0 ซม.

แนวคำตอบและเหตุผล

ถ้าไม่ใส่วงเล็บ 2 * width + length จะคูณ 2 แค่ความกว้าง ซึ่งผิดสูตร

ex_3_3.py
width = float(input("กว้าง: "))
length = float(input("ยาว: "))
print(f"พื้นที่ {width * length} ตร.ซม.")
print(f"เส้นรอบรูป {2 * (width + length)} ซม.")

ข้อ 3.4อายุอยู่ในช่วงหรือไม่ปานกลาง

กิจกรรมรับคนอายุ 18 ถึง 25 ปี (รวม 18 และ 25) ให้ตรวจว่าอายุที่ผู้ใช้พิมพ์เข้าเกณฑ์หรือไม่

เข้าใจโจทย์
โจทย์ให้
อายุ เช่น 21
ต้องหา
เข้าเกณฑ์: True
วิธีคิด
  1. รับอายุเป็น int
  2. “รวม 18 และ 25” แปลว่าใช้ <=
  3. เขียนแบบต่อกัน 18 <= age <= 25
ตัวอย่างผลลัพธ์ · ตัวที่ขีดเส้นใต้คือค่าที่ผู้ใช้พิมพ์
อายุ: 21
เข้าเกณฑ์: True

แนวคำตอบและเหตุผล

18 <= age <= 25 มีความหมายเท่ากับ age >= 18 and age <= 25 แต่อ่านง่ายกว่า

ex_3_4.py
age = int(input("อายุ: "))
print(f"เข้าเกณฑ์: {18 <= age <= 25}")

ข้อ 3.5แลกธนบัตรท้าทาย

รับจำนวนเงิน แล้วแลกเป็นธนบัตร 1000, 500 และ 100 บาทให้ได้จำนวนใบน้อยที่สุด พร้อมบอกเศษที่เหลือ

เข้าใจโจทย์
โจทย์ให้
จำนวนเงิน เช่น 2870
ต้องหา
จำนวนธนบัตรแต่ละชนิด และเงินที่เหลือ
วิธีคิด
  1. เริ่มจากธนบัตรใหญ่สุด: ใช้ // 1000 หาจำนวนใบ
  2. ใช้ % 1000 หาเงินที่เหลือ แล้วทำต่อกับ 500 และ 100
  3. เก็บเงินที่เหลือในตัวแปรเดิมด้วย %=
ตัวอย่างผลลัพธ์ · ตัวที่ขีดเส้นใต้คือค่าที่ผู้ใช้พิมพ์
จำนวนเงิน: 2870
1000 บาท: 2 ใบ
500 บาท: 1 ใบ
100 บาท: 3 ใบ
เหลือ 70 บาท

แนวคำตอบและเหตุผล

แต่ละขั้นใช้ // นับจำนวนใบ แล้วใช้ %= เก็บเฉพาะเงินที่ยังไม่ได้แลกไปคำนวณต่อในขั้นถัดไป

ex_3_5.py
money = int(input("จำนวนเงิน: "))
print("1000 บาท:", money // 1000, "ใบ")
money %= 1000
print("500 บาท:", money // 500, "ใบ")
money %= 500
print("100 บาท:", money // 100, "ใบ")
money %= 100
print("เหลือ", money, "บาท")

ข้อ 3.6สิทธิ์ส่งฟรีท้าทาย

ร้านส่งฟรีเมื่อยอดซื้อตั้งแต่ 500 บาท หรือเป็นสมาชิก ให้ตรวจสิทธิ์จากยอดซื้อและคำตอบว่าเป็นสมาชิกไหม (y/n)

เข้าใจโจทย์
โจทย์ให้
ยอดซื้อ 320 และเป็นสมาชิก (y)
ต้องหา
ส่งฟรี: True
วิธีคิด
  1. รับยอดเป็น float และสถานะเป็นข้อความ
  2. เปลี่ยนคำตอบเป็น bool ด้วย member == "y"
  3. ใช้ or เพราะเข้าเงื่อนไขข้อใดข้อหนึ่งก็พอ
ตัวอย่างผลลัพธ์ · ตัวที่ขีดเส้นใต้คือค่าที่ผู้ใช้พิมพ์
ยอดซื้อ: 320
เป็นสมาชิกไหม (y/n): y
ส่งฟรี: True

แนวคำตอบและเหตุผล

ยอด 320 ไม่ถึง 500 (False) แต่เป็นสมาชิก (True) เมื่อรวมด้วย or จึงได้ True

ex_3_6.py
total = float(input("ยอดซื้อ: "))
member = input("เป็นสมาชิกไหม (y/n): ")
free_shipping = total >= 500 or member == "y"
print(f"ส่งฟรี: {free_shipping}")
