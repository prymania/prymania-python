CHAPTER 03 · พื้นฐาน

ตัวดำเนินการและนิพจน์

คำนวณตัวเลข เปรียบเทียบค่า และประกอบเงื่อนไขเชิงตรรกะ

เมื่อจบบทนี้ นิสิตจะทำได้
  • เลือก operator ให้ตรงงานและคาดเดาลำดับคำนวณได้
  • ตัวดำเนินการเลขคณิต
  • เปรียบเทียบแล้วได้ bool

แนวคิดและตัวอย่าง

แผนการเรียนบทนี้

บทนี้ต่อจากการรู้จักชนิดข้อมูล โดยฝึกแปลงโจทย์คำนวณให้เป็น expression ที่ Python เข้าใจ ให้แยกการกำหนดค่า (=) ออกจากการเปรียบเทียบ (==) และลองไล่ผลของ // กับ % ด้วยตัวเลขที่หารไม่ลงตัวก่อนนำไปเขียนโปรแกรมจริง

วิธีฝึก: อ่านโจทย์ → ระบุข้อมูลเข้าและผลที่ต้องการ → ทำนาย output → รันและตรวจทีละขั้น → อธิบายด้วยคำของตนเองว่าเหตุใดจึงได้ผลเช่นนั้น

03.1 ตัวดำเนินการเลขคณิต

`+ - * /` ใช้คำนวณพื้นฐาน ส่วน `//` หารปัดลง, `%` หาเศษ และ `**` ยกกำลัง

ลองคิดเป็นขั้น

ก่อนเขียน ให้แยกข้อมูลที่โจทย์ให้ สิ่งที่ต้องการให้โปรแกรมทำ และผลลัพธ์ที่ควรได้ จากนั้นเลือกแนวคิดนี้มาจัดลำดับวิธีทำ ทดลองรันด้วยค่าตัวอย่าง แล้วตรวจผลทีละบรรทัด ถ้าผลไม่ตรง ให้เทียบค่าตั้งต้นและแต่ละขั้นกับสิ่งที่คาดไว้ก่อนเปลี่ยนโค้ด

03.2 เปรียบเทียบแล้วได้ bool

`==`, `!=`, `<`, `<=`, `>` และ `>=` ให้ผล True หรือ False อย่าสับสน `=` ที่กำหนดค่ากับ `==` ที่เปรียบเทียบ

ลองคิดเป็นขั้น

ก่อนเขียน ให้แยกข้อมูลที่โจทย์ให้ สิ่งที่ต้องการให้โปรแกรมทำ และผลลัพธ์ที่ควรได้ จากนั้นเลือกแนวคิดนี้มาจัดลำดับวิธีทำ ทดลองรันด้วยค่าตัวอย่าง แล้วตรวจผลทีละบรรทัด ถ้าผลไม่ตรง ให้เทียบค่าตั้งต้นและแต่ละขั้นกับสิ่งที่คาดไว้ก่อนเปลี่ยนโค้ด

03.3 เชื่อมเงื่อนไข

`and` ต้องจริงทั้งคู่, `or` จริงอย่างน้อยหนึ่งด้าน และ `not` กลับค่าความจริง ใช้วงเล็บช่วยให้เห็นกลุ่มเงื่อนไข

ตัวอย่าง 03.1 · หารแบบต่าง ๆ

แนวคิด: ลองหารเดียวกันด้วย /, // และ % แล้วอธิบายว่าแต่ละตัวตอบคำถามคนละแบบ

Python source
print(17 / 5)
print(17 // 5)
print(17 % 5)
print(2 ** 5)
Output
3.4
3
2
32
อธิบายทีละขั้น
  1. เครื่องหมาย / ให้ผลหารทศนิยม
  2. // ได้จำนวนรอบเต็ม
  3. % ได้เศษที่เหลือ
  4. ** ใช้ยกกำลัง

ตัวอย่าง 03.2 · ประกอบเงื่อนไข

แนวคิด: ตรวจว่านักศึกษาผ่านเกณฑ์คะแนน และแสดงค่าความจริง

Python source
score = 76
has_submitted = True
passed = score >= 50 and has_submitted

print(passed)
print(score % 2 == 0)
Output
True
True
อธิบายทีละขั้น
  1. เปรียบเทียบ score กับเกณฑ์ 50
  2. and ทำให้ต้องส่งงานด้วยจึงถือว่าผ่าน
  3. บรรทัดสุดท้ายถามว่าคะแนนเป็นเลขคู่หรือไม่

ตัวอย่าง 03.3 · แยกเวลาเป็นชั่วโมงและนาที

แนวคิด: เมื่อมีจำนวนนาทีรวม ใช้ // หา hour เต็ม และ % หาเศษนาทีที่เหลือ

Python source
total_minutes = 157
hours = total_minutes // 60
minutes = total_minutes % 60
print(f"{hours} hours {minutes} minutes")
print(157 / 60)
Output
2 hours 37 minutes
2.6166666666666667
อธิบายทีละขั้น
  1. // ใช้หารจำนวนเต็ม ไม่ใช่หารแล้วตัดข้อความ
  2. % คืนเศษหลังหาร
  3. / ยังให้ผลลัพธ์แบบทศนิยม จึงตอบโจทย์คนละแบบ

แบบฝึกหัดท้ายบท

ทำจากข้อพื้นฐานไปข้อท้าทาย ก่อนเขียนให้จดข้อมูลที่โจทย์ให้ สิ่งที่ต้องหา และลำดับการทำงานสั้น ๆ จากนั้นทำนาย output แล้วรันตรวจ รายการตรวจช่วยไล่เงื่อนไขทีละข้อ หากยังติดให้ย้อนอ่านหัวข้อที่เกี่ยวข้องก่อนเปิดเฉลย ซึ่งมีแนวคิดและ source code ที่รันตรวจแล้ว

ข้อ 03.1แบ่งขนม★ ง่าย

มีขนม 23 ชิ้น แบ่งให้เพื่อน 4 คนเท่ากัน จงหาว่าแต่ละคนได้กี่ชิ้นและเหลือกี่ชิ้น

  • ใช้ // หาจำนวนชิ้นต่อคน
  • ใช้ % หาเศษที่เหลือ
  • แสดงสองค่าคนละบรรทัด
ตัวอย่างผลลัพธ์
คนละ 5 ชิ้น
เหลือ 3 ชิ้น

แนวคำตอบและเหตุผล

การแบ่งจำนวนสิ่งของเต็มชิ้นต้องใช้หารปัดลงร่วมกับหาเศษ

snacks = 23
friends = 4
each = snacks // friends
left = snacks % friends

print(f"คนละ {each} ชิ้น")
print(f"เหลือ {left} ชิ้น")

ข้อ 03.2พื้นที่สี่เหลี่ยม★ ง่าย

คำนวณพื้นที่และเส้นรอบรูปของสี่เหลี่ยมผืนผ้ากว้าง 7.5 ยาว 12

  • พื้นที่ = กว้าง × ยาว
  • เส้นรอบรูป = 2 × (กว้าง + ยาว)
  • แสดงผลโดยระบุหน่วย
ตัวอย่างผลลัพธ์
พื้นที่ 90.0 ตร.ซม.
รอบรูป 39.0 ซม.

แนวคำตอบและเหตุผล

วงเล็บบอกให้บวกความยาวทั้งสองด้านก่อนคูณสอง

width = 7.5
length = 12
area = width * length
perimeter = 2 * (width + length)

print(f"พื้นที่ {area} ตร.ซม.")
print(f"รอบรูป {perimeter} ซม.")

print(f"ได้รับส่วนลด: {discount}")

ข้อ 03.5แยกธนบัตรและเศษเงิน★ ง่าย

มีเงิน 287 บาท จงหาจำนวนธนบัตร 100 บาทเต็มใบที่ใช้ได้และเงินที่เหลือ โดยยังไม่ต้องทำระบบแลกเหรียญ

  • ใช้ // หาจำนวนธนบัตร
  • ใช้ % หาเงินที่เหลือ
  • แสดงผลพร้อมคำอธิบาย
ตัวอย่างผลลัพธ์
100-baht bills: 2
Remaining: 87 baht

แนวคำตอบและเหตุผล

โจทย์แบ่งของเป็นกลุ่มเท่ากันใช้ // หาได้กี่กลุ่ม และ % หาส่วนที่เหลือ

money = 287
hundreds = money // 100
remaining = money % 100
print(f"100-baht bills: {hundreds}")
print(f"Remaining: {remaining} baht")

ข้อ 03.6ตรวจช่วงคะแนนสองด้าน★★ ปานกลาง

คะแนนมีค่า 63 ต้องตรวจว่าผ่านช่วงคะแนนกิจกรรม 50 ถึง 80 แบบรวมขอบเขตหรือไม่ และตรวจแยกว่าคะแนนหาร 3 ลงตัวหรือไม่

  • สร้าง expression เชื่อมขอบล่างและขอบบนด้วย and
  • ใช้ % ตรวจการหารลงตัว
  • แสดงผล Boolean ทั้งสองข้อ
ตัวอย่างผลลัพธ์
True
True

แนวคำตอบและเหตุผล

comparison chaining ใช้เปรียบเทียบขอบเขตต่อเนื่องได้ตรงกับความหมาย

score = 63
in_range = 50 <= score <= 80
divisible_by_three = score % 3 == 0
print(in_range)
print(divisible_by_three)
