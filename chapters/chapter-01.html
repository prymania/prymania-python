CHAPTER 01 · พื้นฐาน

โครงสร้างโปรแกรม Python, IDE และการรัน

ติดตั้งและเริ่มใช้งาน Python ด้วย Thonny ทำความเข้าใจไฟล์ .py, โครงสร้างคำสั่ง และวิธีรัน/หยุดโปรแกรม

เมื่อจบบทนี้ นิสิตจะทำได้
  • อธิบาย interpreter กับ IDE ได้ สร้างไฟล์ Python บันทึก และรันโปรแกรมพร้อมอ่าน error เบื้องต้น
  • Python program ทำงานอย่างไร
  • เลือก IDE สำหรับผู้เริ่มเรียน: Thonny

แนวคิดและตัวอย่าง

แผนการเรียนบทนี้

บทนี้ตั้งใจให้เริ่มจากสิ่งที่นิสิตทำได้จริงในคาบแรก: เปิด Thonny พิมพ์โปรแกรม บันทึกไฟล์ และรันจนเห็นผลใน Shell ให้แยกความหมายของ editor, interpreter และ Shell ออกจากกัน เพราะการแก้ปัญหาติดตั้งหรือรันไม่ออกต้องรู้ว่าแต่ละส่วนทำหน้าที่ใด

วิธีฝึก: อ่านโจทย์ → ระบุข้อมูลเข้าและผลที่ต้องการ → ทำนาย output → รันและตรวจทีละขั้น → อธิบายด้วยคำของตนเองว่าเหตุใดจึงได้ผลเช่นนั้น

01.1 Python program ทำงานอย่างไร

เราเขียนคำสั่งเป็นข้อความในไฟล์นามสกุล .py จากนั้น Python interpreter อ่านและทำคำสั่งตามลำดับจากบนลงล่าง โปรแกรมจึงต้องเริ่มจากคำสั่งที่ให้ผลลัพธ์สังเกตได้ เช่น print แล้วค่อยเพิ่มการคำนวณและการตัดสินใจทีละส่วน

ลองคิดเป็นขั้น

ก่อนเขียน ให้แยกข้อมูลที่โจทย์ให้ สิ่งที่ต้องการให้โปรแกรมทำ และผลลัพธ์ที่ควรได้ จากนั้นเลือกแนวคิดนี้มาจัดลำดับวิธีทำ ทดลองรันด้วยค่าตัวอย่าง แล้วตรวจผลทีละบรรทัด ถ้าผลไม่ตรง ให้เทียบค่าตั้งต้นและแต่ละขั้นกับสิ่งที่คาดไว้ก่อนเปลี่ยนโค้ด

01.2 เลือก IDE สำหรับผู้เริ่มเรียน: Thonny

แนะนำ Thonny เพราะติดตั้งและเริ่มใช้ได้ง่าย มี editor, Python Shell, ปุ่ม Run/Stop และเครื่องมือ debug อยู่ในหน้าต่างเดียว ไม่ใช่ VS Code และไม่ได้ใช้ AI สร้างหรือเติมโค้ดให้ ระหว่างฝึกนิสิตจึงต้องคิดและพิมพ์คำสั่งเอง ส่วนการเติมคำสั่งพื้นฐานสามารถปิดได้ใน Tools > Options > Editor

ลองคิดเป็นขั้น

ก่อนเขียน ให้แยกข้อมูลที่โจทย์ให้ สิ่งที่ต้องการให้โปรแกรมทำ และผลลัพธ์ที่ควรได้ จากนั้นเลือกแนวคิดนี้มาจัดลำดับวิธีทำ ทดลองรันด้วยค่าตัวอย่าง แล้วตรวจผลทีละบรรทัด ถ้าผลไม่ตรง ให้เทียบค่าตั้งต้นและแต่ละขั้นกับสิ่งที่คาดไว้ก่อนเปลี่ยนโค้ด

01.3 แยก editor, shell และ interpreter

Editor คือพื้นที่เขียนและบันทึกไฟล์ ส่วน Shell คือพื้นที่ทดลองคำสั่งสั้น ๆ และดูผลทันที Interpreter คือโปรแกรม Python ที่รับ source code ไปรัน ใน Thonny เลือก interpreter ที่ติดตั้งมาพร้อมโปรแกรมได้จากมุมขวาล่าง

ลองคิดเป็นขั้น

ก่อนเขียน ให้แยกข้อมูลที่โจทย์ให้ สิ่งที่ต้องการให้โปรแกรมทำ และผลลัพธ์ที่ควรได้ จากนั้นเลือกแนวคิดนี้มาจัดลำดับวิธีทำ ทดลองรันด้วยค่าตัวอย่าง แล้วตรวจผลทีละบรรทัด ถ้าผลไม่ตรง ให้เทียบค่าตั้งต้นและแต่ละขั้นกับสิ่งที่คาดไว้ก่อนเปลี่ยนโค้ด

01.4 โครงสร้างไฟล์และการเยื้องบรรทัด

คำสั่ง Python วางต่อกันตามลำดับ ใช้ # เริ่ม comment เพื่ออธิบายเหตุผล และใช้การเยื้อง 4 ช่องเพื่อบอกว่าคำสั่งใดอยู่ในบล็อกเดียวกัน ควรบันทึกงานเป็นไฟล์ .py ในโฟลเดอร์รายวิชาของตน ไม่ใช้ชื่อไฟล์ชนกับชื่อ package เช่น random.py

ลองคิดเป็นขั้น

ก่อนเขียน ให้แยกข้อมูลที่โจทย์ให้ สิ่งที่ต้องการให้โปรแกรมทำ และผลลัพธ์ที่ควรได้ จากนั้นเลือกแนวคิดนี้มาจัดลำดับวิธีทำ ทดลองรันด้วยค่าตัวอย่าง แล้วตรวจผลทีละบรรทัด ถ้าผลไม่ตรง ให้เทียบค่าตั้งต้นและแต่ละขั้นกับสิ่งที่คาดไว้ก่อนเปลี่ยนโค้ด

01.5 รัน บันทึก และอ่านข้อผิดพลาด

บันทึกไฟล์ก่อนกด Run (ปุ่มสีเขียวหรือ F5 ใน Thonny) ผลแสดงใน Shell เมื่อแก้โค้ดให้รันใหม่ได้ หากมี error ให้อ่านชนิดและข้อความท้าย traceback แล้วกลับไปดูบรรทัดที่ระบุ แก้ทีละสาเหตุ ไม่ต้องลบโปรแกรมเขียนใหม่ทั้งหมด

ลองคิดเป็นขั้น

ก่อนเขียน ให้แยกข้อมูลที่โจทย์ให้ สิ่งที่ต้องการให้โปรแกรมทำ และผลลัพธ์ที่ควรได้ จากนั้นเลือกแนวคิดนี้มาจัดลำดับวิธีทำ ทดลองรันด้วยค่าตัวอย่าง แล้วตรวจผลทีละบรรทัด ถ้าผลไม่ตรง ให้เทียบค่าตั้งต้นและแต่ละขั้นกับสิ่งที่คาดไว้ก่อนเปลี่ยนโค้ด

ตัวอย่าง 01.1 · โปรแกรมแรก: แสดงผลทีละบรรทัด

แนวคิด: เริ่มจากคำสั่งที่เห็นผลทันที เพื่อยืนยันว่า editor, interpreter และหน้าต่าง output ทำงานครบ

Python source
print("Hello, Python!")
print("I am ready to learn.")
print(2 + 3)
Output
Hello, Python!
I am ready to learn.
5
อธิบายทีละขั้น
  1. พิมพ์คำสั่งใน editor แล้วบันทึกเป็น hello.py
  2. กด Run หรือ F5; Thonny ส่งไฟล์ไปให้ interpreter
  3. Shell แสดงข้อความตามลำดับ และคำนวณ 2 + 3 ก่อนแสดงผลบรรทัดสุดท้าย

ตัวอย่าง 01.2 · คอมเมนต์กับลำดับคำสั่ง

แนวคิด: มองโปรแกรมเป็นสูตรที่อ่านจากบนลงล่าง คอมเมนต์บอกเหตุผลให้คนอ่าน แต่ interpreter ข้ามบรรทัดนั้น

Python source
# Convert minutes to hours and minutes
total_minutes = 135
hours = total_minutes // 60
minutes = total_minutes % 60
print(f"{hours} hours {minutes} minutes")
Output
2 hours 15 minutes
อธิบายทีละขั้น
  1. comment เริ่มด้วย # และไม่ใช่คำสั่งที่โปรแกรมรัน
  2. คำนวณชั่วโมงเต็มก่อนด้วย //
  3. ใช้ % หาเศษนาที แล้วรวมผลใน f-string

ตัวอย่าง 01.3 · ทดลองสั้นใน Python Shell

แนวคิด: Shell เหมาะกับการลองคำสั่งเดี่ยว ๆ ส่วนงานที่ต้องเก็บหรือส่งควรบันทึกเป็น .py

Python source
values = [3, 7, 10]
sum(values)
max(values)
len(values)
Output
(ไม่มีข้อความแสดงผล)
อธิบายทีละขั้น
  1. แต่ละบรรทัดใน Shell รันได้ทันที
  2. Shell แสดงค่าคืนจากนิพจน์ที่พิมพ์
  3. เมื่อต้องการส่งงานให้คัดคำสั่งลง editor และบันทึกเป็นไฟล์

ตัวอย่าง 01.4 · แก้ error จากข้อความที่อ่านได้

แนวคิด: สังเกตความต่างระหว่างข้อความกับตัวแปร และแก้ที่ชื่อซึ่ง interpreter หาไม่พบ

แบบฝึกหัดท้ายบท

ทำจากข้อพื้นฐานไปข้อท้าทาย ก่อนเขียนให้จดข้อมูลที่โจทย์ให้ สิ่งที่ต้องหา และลำดับการทำงานสั้น ๆ จากนั้นทำนาย output แล้วรันตรวจ รายการตรวจช่วยไล่เงื่อนไขทีละข้อ หากยังติดให้ย้อนอ่านหัวข้อที่เกี่ยวข้องก่อนเปิดเฉลย ซึ่งมีแนวคิดและ source code ที่รันตรวจแล้ว

ข้อ 01.1Hello, Python★ ง่าย

สร้างไฟล์ hello.py ใน Thonny ให้แสดงข้อความสองบรรทัดตามตัวอย่าง ตรวจด้วยว่าบันทึกไฟล์ไว้ในโฟลเดอร์รายวิชาแล้ว ไม่ใช่พิมพ์เฉพาะใน Shell

  • เปิดไฟล์ใหม่ใน editor
  • เขียน print แยกสองบรรทัด
  • บันทึกเป็น hello.py แล้วกด Run/F5
  • อ่านข้อความจาก Shell และเทียบกับตัวอย่าง
ตัวอย่างผลลัพธ์
Hello, Python!
My name is Nina.

แนวคำตอบและเหตุผล

การบันทึกไฟล์ .py ทำให้กลับมาแก้ไขหรือส่งงานได้ ต่างจากคำสั่งชั่วคราวใน Shell

print("Hello, Python!")
print("My name is Nina.")

ข้อ 01.2แนะนำตัวด้วยสามบรรทัด★ ง่าย

เขียนโปรแกรมพิมพ์ชื่อ สาขา และชั้นปีอย่างละหนึ่งบรรทัด ทดลองแก้ข้อมูลแล้วรันซ้ำเพื่อยืนยันว่าได้ output ใหม่

  • เลือกข้อความที่จะพิมพ์สามค่า
  • ใช้ print หนึ่งคำสั่งต่อหนึ่งบรรทัด
  • บันทึกและรันไฟล์
ตัวอย่างผลลัพธ์
Name: Arun
Major: Computer Science
Year: 1

แนวคำตอบและเหตุผล

แยก print ทำให้มองเห็นว่าแต่ละคำสั่งสร้าง output บรรทัดใด

print("Name: Arun")
print("Major: Computer Science")
print("Year: 1")

ข้อ 01.3อ่านลำดับการทำงาน★★ ปานกลาง

ก่อนรัน จงเขียน output ที่คาดว่าจะได้ จากนั้นรันและอธิบายว่าทำไมบรรทัดที่สองมีค่า 12

  • คัดลอกโปรแกรมตามตัวอย่าง
  • ทำนายผลทีละบรรทัดก่อนกด Run
  • อธิบายว่า Python ประมวลผล 5 + 7 ก่อนส่งค่าเข้า print
ตัวอย่างผลลัพธ์
Start
12
Finish

แนวคำตอบและเหตุผล

การทำนายผลก่อนรันช่วยตรวจว่าตนเข้าใจความแตกต่างระหว่างข้อความกับนิพจน์หรือไม่

print("Start")
print(5 + 7)
print("Finish")

ข้อ 01.4จัดรูปแบบโปรแกรมให้อ่านง่าย★★ ปานกลาง

แก้โปรแกรมที่มี comment และการคำนวณเวลาให้ชื่อไฟล์เป็น time_left.py จัดแต่ละคำสั่งบรรทัดใหม่และรันจน output ถูกต้อง

  • คง comment ไว้เพื่อบอกความหมาย
  • ใช้ชื่อตัวแปรสื่อความหมาย
  • บันทึกชื่อไฟล์ .py และตรวจผล 2 hours 15 minutes
ตัวอย่างผลลัพธ์
2 hours 15 minutes

แนวคำตอบและเหตุผล

โค้ดที่จัดบรรทัดและตั้งชื่อดีทำให้อ่านย้อนกลับและหาข้อผิดพลาดได้ง่าย

# 135 minutes is 2 hours and 15 minutes
total_minutes = 135
hours = total_minutes // 60
minutes = total_minutes % 60
print(f"{hours} hours {minutes} minutes")

ข้อ 01.5แก้ syntax error★★ ปานกลาง

โปรแกรมด้านล่างมีเครื่องหมายอัญประกาศปิดหายไป ให้ใช้ข้อความ error ใน Thonny ระบุตำแหน่ง แก้เฉพาะจุด แล้วทดสอบรันอีกครั้ง

  • เริ่มจากรันโค้ดเพื่อดู error จริง
  • หาคำสั่ง print ที่ข้อความปิดไม่ครบ
  • แก้แล้วรันใหม่ให้ได้ output สองบรรทัด
ตัวอย่างผลลัพธ์
Open the file
Run the program

แนวคำตอบและเหตุผล

SyntaxError เกิดก่อนเริ่มทำงาน มักเกิดจากรูปแบบคำสั่ง เช่น วงเล็บหรืออัญประกาศไม่ครบ

print("Open the file")
print("Run the program")

ข้อ 01.6แยก Shell กับไฟล์โปรแกรม★★★ ท้าทาย

ทดลองคำสั่ง 10 * 3 ใน Shell แล้วสร้างไฟล์ multiply.py ที่พิมพ์คำตอบพร้อมข้อความกำกับ อธิบายว่า Shell กับ editor ต่างกันอย่างไร

  • ทดลอง expression ใน Shell
  • เขียนคำสั่ง print ใน editor
  • บันทึกและรันไฟล์ .py
  • ตอบว่าเมื่อใดควรใช้ Shell และเมื่อใดควรใช้ไฟล์
ตัวอย่างผลลัพธ์
10 times 3 = 30

แนวคำตอบและเหตุผล

Shell เหมาะทดลองเร็ว ส่วนไฟล์เก็บโปรแกรมที่ต้องรันซ้ำ แก้ไข และส่ง

answer = 10 * 3
print(f"10 times 3 = {answer}")

ข้อ 01.7ทำ checklist ก่อนส่งงาน★★★ ท้าทาย

สร้างโปรแกรมสรุปข้อมูลรายวิชาให้ทำงานได้จากการเปิดไฟล์ใหม่ใน Thonny ตรวจว่ามีไฟล์นามสกุล .py ไม่มี error และ output ตรงกับค่าที่กำหนด

  • กำหนดชื่อวิชาและจำนวนหน่วยกิต
  • พิมพ์หัวข้อและค่าบน output
  • บันทึกในโฟลเดอร์ที่ถูกต้อง
  • ปิดแล้วเปิดไฟล์เดิมอีกครั้งและรันเพื่อทดสอบ
ตัวอย่างผลลัพธ์
Course: Python Programming
Credits: 3

แนวคำตอบและเหตุผล

ทดสอบเปิดไฟล์และรันซ้ำช่วยจับปัญหาบันทึกผิดตำแหน่งหรือส่งไฟล์ไม่ครบ

course = "Python Programming"
credits = 3
print("Course:", course)
print("Credits:", credits)
