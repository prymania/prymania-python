CHAPTER 05 · พื้นฐาน

การทำซ้ำด้วยลูป

สั่งให้โปรแกรมทำงานซ้ำด้วย for และ while แทนการเขียนคำสั่งเดิมหลายครั้ง

จบบทนี้แล้วทำได้

ใช้ for กับ range และข้อมูลหลายค่า สะสมผลรวม/นับจำนวน ใช้ while เมื่อไม่รู้จำนวนรอบ และควบคุมลูปด้วย break/continue

เนื้อหา

05.1 for กับ range()

for i in range(n): ทำคำสั่งที่เยื้องซ้ำ n รอบ โดยตัวแปร i เปลี่ยนค่าไปทุกรอบ range ไม่รวมตัวเลขสุดท้ายเสมอ

สร้างตัวแปรเริ่มต้น (เช่น total = 0) ไว้ก่อนลูป แล้วเพิ่มค่าในลูปทุกรอบ ตารางด้านล่างไล่ค่าทีละรอบของโค้ดตัวอย่าง

05.4 while: วนจนกว่าเงื่อนไขจะเป็นเท็จ

while เงื่อนไข: ทำซ้ำไปเรื่อย ๆ ตราบที่เงื่อนไขยังจริง เหมาะเมื่อไม่รู้ว่าต้องวนกี่รอบ เช่น รอจนผู้ใช้พิมพ์ถูก ต้องมีคำสั่งที่ทำให้เงื่อนไขเปลี่ยน ไม่อย่างนั้นจะวนไม่จบ

count = 3
while count > 0:
    print(count)
    count -= 1
print("ปล่อยจรวด!")

จำง่าย ๆ ถ้าโปรแกรมวนไม่หยุด กด Ctrl + F2 (Stop) ใน Thonny

05.5 break และ continue

break ออกจากลูปทันที continue ข้ามไปเริ่มรอบถัดไปโดยไม่ทำคำสั่งที่เหลือในรอบนั้น

for n in range(1, 10):
    if n % 2 == 0:
        continue      # ข้ามเลขคู่
    if n > 7:
        break         # เกิน 7 แล้วหยุด
    print(n)

ตัวอย่าง 05.1 · สูตรคูณ

ใช้ for กับ range(1, 13) สร้างแม่สูตรคูณที่ผู้ใช้เลือก

n = int(input("แม่สูตรคูณ: "))
for i in range(1, 13):
    print(f"{n} x {i:>2} = {n * i:>3}")

  3. :>2 และ :>3 จัดตัวเลขชิดขวาให้ตรงกันเป็นคอลัมน์

ตัวอย่าง 05.2 · รับคะแนนจนกว่าจะพิมพ์ -1

ไม่รู้ว่าจะมีกี่คะแนน จึงใช้ while แล้วหยุดเมื่อเจอค่าพิเศษ

Python source
total = 0
count = 0
score = int(input("คะแนน (-1 = จบ): "))
while score != -1:
    total += score
    count += 1
    score = int(input("คะแนน (-1 = จบ): "))

print(f"กรอก {count} คน เฉลี่ย {total / count:.2f}")
Output · ค่าที่ผู้ใช้พิมพ์แสดงต่อท้ายคำถาม
คะแนน (-1 = จบ): 70
คะแนน (-1 = จบ): 85
คะแนน (-1 = จบ): 90
คะแนน (-1 = จบ): -1
กรอก 3 คน เฉลี่ย 81.67
อธิบาย
  1. รับค่าแรกก่อนเข้าลูป เพื่อให้ while มีค่าไว้ตรวจ
  2. ในลูปสะสมผลรวมและนับจำนวน แล้วรับค่าถัดไปเป็นบรรทัดสุดท้าย
  3. เมื่อพิมพ์ -1 เงื่อนไขเป็นเท็จ ลูปจบ แล้วคำนวณค่าเฉลี่ย

    total += i
print(f"ผลรวม 1 ถึง {n} = {total}")

ข้อ 05.4หาค่ามากสุด★★ ปานกลาง

รับคะแนน 5 ค่า แล้วหาคะแนนสูงสุดโดยไม่ใช้ max()

เข้าใจโจทย์
โจทย์ให้
คะแนน 5 ค่า เช่น 67, 82, 75, 91, 58
ต้องหา
คะแนนสูงสุด 91

วิธีคิด

  1. รับค่าแรกเก็บเป็นค่ามากสุดชั่วคราว
  2. วนรับอีก 4 ค่า ถ้าค่าใหม่มากกว่าให้แทนที่
  3. แสดงผลหลังจบลูป
ตัวอย่างผลลัพธ์
คะแนน: 67
คะแนน: 82
คะแนน: 75
คะแนน: 91
คะแนน: 58
คะแนนสูงสุด 91

แนวคำตอบและเหตุผล

เทียบทีละค่ากับค่ามากสุดที่เจอมาแล้ว เป็นวิธีพื้นฐานของ max() ส่วน _ ใช้เป็นชื่อตัวแปรเมื่อไม่ได้ใช้ค่ารอบ

best = int(input("คะแนน: "))
for _ in range(4):
    score = int(input("คะแนน: "))
    if score > best:
        best = score
print(f"คะแนนสูงสุด {best}")

ข้อ 05.5เกมทายตัวเลข★★★ ท้าทาย

โปรแกรมมีเลขลับ 37 ให้ผู้ใช้ทายไปเรื่อย ๆ บอกใบ้ว่า มากไป/น้อยไป จนกว่าจะถูก แล้วบอกว่าทายกี่ครั้ง

เข้าใจโจทย์
โจทย์ให้
เลขลับ 37 และคำทาย 50, 25, 37
ต้องหา
คำใบ้ทุกครั้ง และ ถูกต้อง! ทาย 3 ครั้ง

วิธีคิด

  1. ไม่รู้จำนวนรอบ จึงใช้ while
  2. ตั้ง guess เริ่มต้นเป็นค่าที่ยังไม่ถูก เช่น 0
  3. ในลูปรับค่า นับครั้ง แล้วใช้ if / elif บอกใบ้
ตัวอย่างผลลัพธ์
ทายเลข 1-100: 50
มากไป
ทายเลข 1-100: 25
น้อยไป
ทายเลข 1-100: 37
ถูกต้อง! ทาย 3 ครั้ง

แนวคำตอบและเหตุผล

ลูปจบเองเมื่อ guess == secret จึงไม่ต้องใช้ break ข้อความ “ถูกต้อง” อยู่นอกลูปเพราะทำครั้งเดียวตอนจบ

secret = 37
guess = 0
tries = 0
while guess != secret:
    guess = int(input("ทายเลข 1-100: "))
    tries += 1
    if guess > secret:
        print("มากไป")
    elif guess < secret:
        print("น้อยไป")
print(f"ถูกต้อง! ทาย {tries} ครั้ง")

ข้อ 05.6ใส่รหัส PIN ได้ 3 ครั้ง★★★ ท้าทาย

PIN ที่ถูกคือ 1234 ให้ผู้ใช้ลองได้ไม่เกิน 3 ครั้ง ถ้าถูกให้ขึ้น เข้าสู่ระบบสำเร็จ และหยุดถาม ถ้าผิดครบ 3 ครั้งให้ขึ้น บัตรถูกระงับ

เข้าใจโจทย์
โจทย์ให้
PIN ที่ผู้ใช้พิมพ์: 1111, 1234
ต้องหา
แจ้งผิด 1 ครั้ง แล้ว เข้าสู่ระบบสำเร็จ

วิธีคิด

  1. วน for attempt in range(3)
  2. ถ้าถูกให้แสดงผลแล้ว break
  3. ใช้ตัวแปร success จำผล แล้วตรวจหลังลูป
ตัวอย่างผลลัพธ์
PIN: 1111
PIN ไม่ถูกต้อง
PIN: 1234
เข้าสู่ระบบสำเร็จ

แนวคำตอบและเหตุผล

break หยุดถามทันทีเมื่อถูก ตัวแปร success บอกว่าออกจากลูปเพราะถูก หรือเพราะครบ 3 ครั้ง

success = False
for attempt in range(3):
    pin = input("PIN: ")
    if pin == "1234":
        success = True
        break
    print("PIN ไม่ถูกต้อง")

if success:
    print("เข้าสู่ระบบสำเร็จ")
else:
    print("บัตรถูกระงับ")
