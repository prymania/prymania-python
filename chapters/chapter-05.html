CHAPTER 05 · พื้นฐาน

การทำซ้ำด้วยลูป

ทำคำสั่งซ้ำอย่างควบคุมได้ด้วย for, while และ range

เมื่อจบบทนี้ นิสิตจะทำได้
  • เลือกใช้ลูปให้เหมาะกับจำนวนรอบและติดตามค่าระหว่างวนซ้ำ
  • for วนผ่านสมาชิก
  • สะสมค่าอย่างระมัดระวัง

แนวคิดและตัวอย่าง

แผนการเรียนบทนี้

ลูปช่วยเลิกเขียนคำสั่งเดิมซ้ำด้วยมือ ก่อนสร้างลูปให้ระบุสามอย่าง: ค่าเริ่มต้น สิ่งที่เปลี่ยนในแต่ละรอบ และเงื่อนไขหยุด ตัวอย่างแรกใช้จำนวนรอบที่รู้แน่ด้วย for ส่วน while ใช้เมื่อกำลังทำซ้ำจนกว่าจะถึงสถานะหนึ่ง

วิธีฝึก: อ่านโจทย์ → ระบุข้อมูลเข้าและผลที่ต้องการ → ทำนาย output → รันและตรวจทีละขั้น → อธิบายด้วยคำของตนเองว่าเหตุใดจึงได้ผลเช่นนั้น

05.1 for วนผ่านสมาชิก

เหมาะเมื่อมีชุดข้อมูลหรือต้องทำซ้ำตามจำนวนรอบ `range(1, 5)` สร้างเลข 1 ถึง 4 โดยไม่รวมปลายขวา

ลองคิดเป็นขั้น

ก่อนเขียน ให้แยกข้อมูลที่โจทย์ให้ สิ่งที่ต้องการให้โปรแกรมทำ และผลลัพธ์ที่ควรได้ จากนั้นเลือกแนวคิดนี้มาจัดลำดับวิธีทำ ทดลองรันด้วยค่าตัวอย่าง แล้วตรวจผลทีละบรรทัด ถ้าผลไม่ตรง ให้เทียบค่าตั้งต้นและแต่ละขั้นกับสิ่งที่คาดไว้ก่อนเปลี่ยนโค้ด

05.2 สะสมค่าอย่างระมัดระวัง

กำหนดค่าเริ่มต้นก่อนลูป แล้วอัปเดตในแต่ละรอบ ตัวแปรสะสม เช่น total ต้องเริ่มจาก 0

ลองคิดเป็นขั้น

ก่อนเขียน ให้แยกข้อมูลที่โจทย์ให้ สิ่งที่ต้องการให้โปรแกรมทำ และผลลัพธ์ที่ควรได้ จากนั้นเลือกแนวคิดนี้มาจัดลำดับวิธีทำ ทดลองรันด้วยค่าตัวอย่าง แล้วตรวจผลทีละบรรทัด ถ้าผลไม่ตรง ให้เทียบค่าตั้งต้นและแต่ละขั้นกับสิ่งที่คาดไว้ก่อนเปลี่ยนโค้ด

05.3 while วนจนเงื่อนไขเปลี่ยน

ใช้เมื่อจำนวนรอบยังไม่ทราบล่วงหน้า ทุกทางเดินควรมีโอกาสเปลี่ยนเงื่อนไข ไม่เช่นนั้นจะเกิดลูปไม่รู้จบ

ตัวอย่าง 05.1 · รวมเลขด้วย for

แนวคิด: สะสมเลข 1 ถึง 5 ทีละรอบและพิมพ์ผลสุดท้าย

Python source
total = 0
for number in range(1, 6):
    total += number

print(total)
Output
15
อธิบายทีละขั้น
  1. range(1, 6) ให้เลขตั้งแต่ 1 ถึง 5
  2. แต่ละรอบนำ number มาบวก total
  3. หลังจบลูป total เป็นผลรวม

ตัวอย่าง 05.2 · นับถอยหลังด้วย while

แนวคิด: ลดตัวนับทีละหนึ่งและหยุดเมื่อถึงศูนย์

Python source
countdown = 3
while countdown > 0:
    print(countdown)
    countdown -= 1
print("เริ่มได้")
Output
3
2
1
เริ่มได้
อธิบายทีละขั้น
  1. ตรวจเงื่อนไขก่อนเข้ารอบ
  2. พิมพ์ค่าปัจจุบัน
  3. ลดค่าตัวแปรเพื่อให้ลูปเข้าใกล้จุดหยุด

ตัวอย่าง 05.3 · เก็บผลระหว่างวนรอบ

แนวคิด: แสดงค่ารวมสะสมเพื่อดูว่าลูปเปลี่ยนสถานะอย่างไรในแต่ละรอบ

Python source
total = 0
for price in [35, 20, 45]:
    total += price
    print(f"added {price}, running total {total}")
print(f"final total {total}")
Output
added 35, running total 35
added 20, running total 55
added 45, running total 100
final total 100
อธิบายทีละขั้น
  1. total เริ่มที่ 0 ก่อนเริ่มลูป
  2. แต่ละรอบเพิ่มราคาหนึ่งรายการ
  3. print ในลูปเห็นผลสะสม ส่วน print ท้ายลูปแสดงผลสุดท้าย

แบบฝึกหัดท้ายบท

ทำจากข้อพื้นฐานไปข้อท้าทาย ก่อนเขียนให้จดข้อมูลที่โจทย์ให้ สิ่งที่ต้องหา และลำดับการทำงานสั้น ๆ จากนั้นทำนาย output แล้วรันตรวจ รายการตรวจช่วยไล่เงื่อนไขทีละข้อ หากยังติดให้ย้อนอ่านหัวข้อที่เกี่ยวข้องก่อนเปิดเฉลย ซึ่งมีแนวคิดและ source code ที่รันตรวจแล้ว

แนวคำตอบและเหตุผล

นิพจน์คูณใน f-string ทำให้ผลคำนวณและรูปแบบอยู่บรรทัดเดียวกัน

for factor in range(1, 6):
    print(f"7 x {factor} = {7 * factor}")

ข้อ 05.4นับจำนวนวันที่ถึงเป้าหมาย★★★ ท้าทาย

เริ่มอ่านหนังสือวันละ 20 นาที เพิ่มเวลาวันละ 5 นาที ต้องใช้กี่วันจึงอ่านได้อย่างน้อย 40 นาที

  • เริ่มจำนวนวันและเวลาต่อวัน
  • วน while ตราบใดเวลายังต่ำกว่าเป้าหมาย
  • เพิ่มเวลาและนับวันในแต่ละรอบ
ตัวอย่างผลลัพธ์
5 วัน, วันละ 40 นาที

แนวคำตอบและเหตุผล

เริ่มนับวันแรกเป็น 1 แล้วเพิ่มทั้งวันและเวลาในแต่ละรอบ

minutes = 20
days = 1
while minutes < 40:
    minutes += 5
    days += 1
print(f"{days} วัน, วันละ {minutes} นาที")

แนวคำตอบและเหตุผล

ตัวแปรนับต้องเริ่มก่อนเข้าลูปและเพิ่มเฉพาะเมื่อเงื่อนไขเป็นจริง

temps = [29, 34, 31, 27, 36]
hot_days = 0
for temp in temps:
    if temp >= 32:
        hot_days += 1
print(hot_days)

ข้อ 05.6สร้างตารางคูณย่อ★★ ปานกลาง

แสดงผลคูณของเลข 6 ตั้งแต่ 1 ถึง 8 โดยแสดงเฉพาะผลลัพธ์ที่มากกว่า 30

  • วนตัวคูณด้วย range
  • คำนวณ product ในแต่ละรอบ
  • ใช้ if คัดกรองค่าที่ต้องแสดง
ตัวอย่างผลลัพธ์
6 x 6 = 36
6 x 7 = 42
6 x 8 = 48

แนวคำตอบและเหตุผล

การวาง if ในลูปช่วยกรองผลของแต่ละรอบโดยไม่ต้องสร้างรายการใหม่

for factor in range(1, 9):
    product = 6 * factor
    if product > 30:
        print(f"6 x {factor} = {product}")
