💻 ในโลกคอมพิวเตอร์: นับคนไม่ซ้ำโดยไม่รู้ว่าเป็นใคร
  • เว็บทั่วไปจำผู้ใช้ด้วยคุกกี้ คือเก็บรหัสประจำตัวไว้ในเบราว์เซอร์ แล้วตามดูได้ข้ามวันข้ามเว็บ
  • เว็บนี้ใช้ GoatCounter ซึ่งไม่ใช้คุกกี้ แต่เอา IP + ชนิดเบราว์เซอร์ + ค่าสุ่มลับ ไปเข้าฟังก์ชันแฮช ได้รหัสชั่วคราวมาแทน
  • คนเดิมเปิดซ้ำ → ได้รหัสเดิม → ไม่นับเพิ่ม · แต่ย้อนจากรหัสกลับไปหา IP ไม่ได้ และค่าสุ่มเปลี่ยนทุกไม่กี่ชั่วโมง จึงตามตัวข้ามวันไม่ได้
  • ลองเองใน Python ได้: import hashlib แล้ว hashlib.sha256(b"hello").hexdigest() ข้อความเดิมได้ผลเดิมทุกครั้ง แต่ย้อนกลับไม่ได้ — เป็นเครื่องมือเดียวกับที่ใช้เก็บรหัสผ่านและตรวจไฟล์ดาวน์โหลด
